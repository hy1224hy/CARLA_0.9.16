# 三步验证：预先登记的解释规则

固定弱红u1000，红0/1冻结；蓝2/3学习，公共20/2接口。Town05，俯视跟随，无RGB。单外层seed42，A/B是两个学习器。正式红方资格及驾驶验收阈值不变。

|组|奖励|每队每次更新回合数|训练预算|
|---|---|---:|---:|
|N4|R2中对抗进度、危险带、主要事件及严重险情项置零，正常驾驶成本保持|4|24000 world ticks|
|R4|原R2|4|24000 world ticks|
|R16|原R2|16|24000 world ticks|

预算以A+B合计实际训练ticks计算，包含reset/setup；完整更新可能少量超出。评估、失败尝试及清理另外报告。学习率沿用72k horizon，避免缩短停止预算时同时加快学习率衰减。其余PPO参数不变。每组0/约12k/约24k各144冻结回合：每队24个相同配对案例，C0/C1/C2。全程最多1296冻结回合，不使用selection/test调参。正常驾驶组不是历史双车基础训练的重现。

第一步观察真实采样动作、pre-tanh z的log概率、独立GAE、终止与截断bootstrap、退场后团队折扣回报。审计使用保存/恢复RNG，不改PPO目标或梯度。离线检查确认审计与原路径的Actor/Critic更新完全相同。保存真实轨迹、前两批buffer和每次更新的策略/熵梯度、代理目标及概率变化。每个正优势样本都增大概率不是共享神经网络的保证；看优势加权方向和完整代理目标。

解释规则：

- N4也退化：对抗奖励不是退化的必要条件，继续查驾驶目标、探索、优化与迁移；不能因此证明R2无问题。
- N4改善而R4退化：对抗奖励组合/信用分配成为重点，不能直接归因于某一个分项。
- R16优于R4：支持采样批量及伴随更新频率有影响；单seed不能证明因果普遍性。
- 同批代理目标改善而固定案例退化：优化代理目标不等于改善环境任务，重点看优势估计、分布覆盖与奖励对应关系。

衡量成功按层报告：

1. 工程正确：数据、动作、log概率、终止及数值检查通过。未实际出现的分支保留未覆盖状态。
2. 学习有效：同奖励、相同冻结案例上回报改善，同时蓝方坏例减少、进度和驾驶质量改善。不同奖励组的回报绝对值不直接排序。
3. 对抗效果：单列接触前持续预测冲突、TET/TIT、无接触解除、真实碰撞、几何接触未确认及观察截断。分别报告全部险情、事件资格险情及完整驾驶质量下的险情，避免把碰撞次数当攻击能力。
4. 归因与复验：与C1及初始Actor按案例配对，报告红方效率/完成及蓝方质量；自然失败不能计为新增攻击成果。完整驾驶未知不能补为合格或不合格。无接触解除与完整驾驶联合率是保守证据，不能代替全部危险交互分布。
5. 正式比较还需要独立外层seed、未用于调参的场景和合格红方。24例只做工程诊断，不把A/B当独立seed，不调整阈值放行。
