# R5 首轮完整反馈与 R5a 单变量修改理由

分析时间：2026-11-08，依据 R5_original_u100/analysis.json、training_u100_analysis.json 及原始评估回合。

## 实际结果
R5 首次完整训练100 updates、3200训练回合。主基线是核验与原始基础actor一致的base_u0，固定红车；A/B是同seed42下两条优化器流，不是独立训练种子。基础与候选selection均48/48有效，另外A/B各24场景×4替换模式=96回合，合计192策略替换回合；未接触完整四元组A14/24、B13/24，排除A10/B11组，必须报告排除带来的场景选择偏差。

确定性selection中红车成功率A从54.2%升66.7%、B从50%升58.3%。团队碰撞率A16.7%降0%、B20.8%降12.5%，离路均从8.3%降0%。A仍有1/24规则违规。不同回放碰撞存在变化，替换评估none模式碰撞A12.5%、B25%，不能把一次零碰撞当可靠结论。

无接触策略替换中，红车进度债联合变化的case均值A=-0.377秒，B=-1.377秒；按pair_id聚类后的均值A=-0.383、B=-0.959秒，95% bootstrap区间A[-3.363,2.585]、B[-2.314,-0.115]。B的驾驶负担联合变化case均值=-0.243、聚类均值=-0.289，95%区间[-0.489,-0.086]。负值表示红车受阻/负担更少。逐车边际未形成稳定正向作用。未接触且持续>=1秒的代理影响场景A2=1/A3=2/B2=2/B3=3。替换none模式样本参考覆盖A2=.947/A3=.967/B2=.941/B3=.924，说明本次评估不是完全没有可用参考，但代理不等同真实因果。

训练末10轮每车平均outcome奖励A2=.0762/A3=.0474/B2=.00735/B3=.0585；基础行驶项约.63-.72、控制及软安全项约-1.99至-2.47、碰撞等硬成本更大。约74%-82%回合有非零对抗信号，正负抵消明显。训练信号不是完全缺失，而是小且不稳定，且没有转化成确定性策略的可靠干扰。前10轮到末10轮红车成功率上升，碰撞下降；后期KL变小同时存在LR线性衰减，不能据此断言数学收敛。EV仍约.09-.45。

## 诊断和本次改动
R5未达到对抗目的；更像形成安全行驶/减轻红车负担的局部策略。分量均值本身不能证明策略梯度由哪项主导，但与独立评估相结合，有理由先检验既有对抗信号量级不足的假设。

本次只将既有outcome_weight由1提高为10。按旧轨迹净奖励0.05量级作粗略估计，10倍约0.5，可接近基础行驶项量级；这只是干预幅度依据，不是对新训练回报的预测，真实结果还受正预算截断及策略变化影响。保留outcome_budget=8、delay_fraction=.7、progress/control权重.03/.3、碰撞-50及其他成本；不新增事件奖金、距离奖金或奖励分量。训练和评估结构保持相同。

目的：以单变量对照判断提高对抗收益相对权重能否让蓝车持续影响红车，而非只优化自身行驶。若仅碰撞增加、仍无非接触配对效应，则本次改动不成功；若交互消失、参考覆盖不足或奖励预算频繁封顶，需据实际轨迹再诊断，不机械继续加倍。每版从同一基础策略重新训练100 updates，避免混入旧奖励训练历史。

## 判断方式与限制
维持同一selection协议、逐车与联合策略替换、非接触持续影响与完整安全报告。测试集尚未使用，不根据测试集调参。只有出现可信影响候选后才冻结并做heldout验证；单seed工程结果不代表论文级泛化证明。红车仍为未正式资格核验的诊断候选，当前结果只支持相应实验范围。

当前聊天智能体在审阅本版全部反馈后指定这次改动；执行脚本只跑本次指定实验，下一版仍需再次分析，不预排扫描。
