## 2026-06-09 — 新方案落地：KL-anchored Policy + 风险增量奖励

### 背景

[train_multi_adversarial_mappo_v2.py](../training/train_multi_adversarial_mappo_v2.py) 训练时观察到：
对抗车（BLUE）实际学到的是"正常开车去 goal，顺路骚扰红车"，而不是真正阻挡红车。
量级估算发现 `base_driving` 里的 `progress/success/time_bonus` 比对抗专属奖励（cut_in/blocking）
高 10–40 倍，对抗信号被完全淹没；想通过调权重平衡，要么没对抗行为、要么自毁。

### 文献调研

完整调研记录在 [对抗训练_文献调研与新方案.md](对抗训练_文献调研与新方案.md)。核心参考：

- **STRIVE (CVPR 2022)** / **Robustifying Imitation (Waymo 2023)**：KL 锚定到正常驾驶 prior
- **AdvSim (ICCV 2021)** / **Causal Influence (ICML 2019)**：因果归因的风险奖励
- **PID-Lagrangian (ICML 2020)**：约束 RL，自适应惩罚

### 新增脚本

[training/train_multi_adversarial_kl_risk.py](../training/train_multi_adversarial_kl_risk.py)

复用 v2 的 `RolloutBuffer / CurriculumLearning / compute_gae* / sample_scenarios_stratified /
make_adversarial_positions / action_tanh_to_env / compute_zero_sum_coef`，只在三处做实质性改动。

### 核心实现差异（与 v2 对照）

#### 1. KL 锚定 actor loss（[L181-189, L514-528](../training/train_multi_adversarial_kl_risk.py)）

每个对抗 actor 在 init 时 `deepcopy` 一份 frozen 副本 `base_actors_frozen[aid]` 作 anchor。
PPO 更新时 actor loss 改为：

```
total_loss = ppo_loss − ent_coef · entropy + β_KL · KL(π_adv ‖ π_base_frozen)
```

KL 计算（pre-tanh 对角高斯，sum over dim, mean over batch）：

```python
def gaussian_kl_diag(mu_p, log_std_p, mu_q, log_std_q):
    var_p = (2.0 * log_std_p).exp()
    var_q = (2.0 * log_std_q).exp()
    kl = log_std_q - log_std_p + (var_p + (mu_p - mu_q)**2) / (2.0 * var_q) - 0.5
    return kl.sum(dim=-1).mean()
```

`β_KL` 默认 0.1（推荐 0.05~0.3）—— β 大则更像正常司机，β 小则对抗自由度大。

#### 2. 风险增量奖励（[L65-138](../training/train_multi_adversarial_kl_risk.py)）

替换原 cut_in/blocking 几何位置奖励，改为 **RED 视角的 TTC 风险评分**：

```python
# 对每对 (red, blue)
if blue 在 red 前方威胁窗口内 (longitudinal ∈ [0.5, threat_radius], |lateral| ≤ threat_lateral):
    closing = red_fwd_speed − blue_fwd_speed_along_red
    if closing > 0.1:
        ttc = longitudinal / closing
        threat += exp(−ttc / threat_tau)
```

只奖励"BLUE 真正让 RED 处于危险"的情况；blue 比 red 快（在跑路）不发放，符合 Causal Influence 思想。

#### 3. 自适应自碰撞惩罚（[L419-424](../training/train_multi_adversarial_kl_risk.py)）

PID-Lagrangian I 项简版，每 update 末根据 BLUE 自碰率反馈调节：

```python
blue_coll_rate = mean(window_blue_collision)
if blue_coll_rate > target_blue_collision_rate:    # ε，默认 0.05
    self_collision_coef *= 1.2                      # 撞太多 → 加大自惩
else:
    self_collision_coef *= 0.95                     # 撞得少 → 适度放松
self_collision_coef = clip(self_collision_coef, 0.1, 10.0)
```

#### 4. base_driving 改"安全驾驶版"（[L141-167](../training/train_multi_adversarial_kl_risk.py)）

`extract_base_driving_safe()` 从 env 的 reward_details 重新提取，**剔除目标导向项**：

| 分量 | v2 系数 | 新方案系数 |
|---|---|---|
| progress | ×0.3 | **×0**（剔除） |
| success | ×0.3 | **×0**（剔除） |
| time_bonus | ×0.3 | **×0**（剔除） |
| collision | ×1.0 | **×0**（由自适应 self_collision_coef 替代） |
| speed | ×0.3 | ×0.3 |
| centering | ×0.2 | ×0.2 |
| yaw | ×0.1 | ×0.1 |
| jerk / steer_rate / safety_lidar / ttc / lane_invasion / step | 保持 | 保持 |

### 总奖励函数

```
r_blue(t) = base_driving_safe(t)              # 仅"安全驾驶"分量
          + threat_coef · threat_reward(t)    # 风险增量（默认 α=2.0）
          + self_collision_coef · collision   # 自适应自碰惩罚
          + zero_sum_coef · (−avg_coop)       # 默认 0（可选）
```

### 新增 CLI 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--beta-kl` | 0.1 | KL 锚定权重 |
| `--threat-coef` | 2.0 | 风险增量奖励权重 |
| `--threat-radius` | 15.0 | 威胁判定纵向距离上限（米） |
| `--threat-lateral` | 2.5 | 威胁判定横向窗口（米） |
| `--threat-tau` | 1.5 | TTC exp 衰减常数（秒） |
| `--target-blue-collision-rate` | 0.05 | 自适应惩罚目标自碰率 ε |
| `--self-collision-coef-init` | 1.0 | 自碰惩罚系数初始值 |
| `--zero-sum-coef` | **0.0** | 默认关闭（与 v2 默认 1.0 不同） |

### 新增 TensorBoard 指标

| 指标 | 含义 |
|---|---|
| `reward/base_safe` | "安全驾驶"奖励均值/步 |
| `reward/threat` | 风险增量奖励均值/步 |
| `reward/self_collision` | 自适应自碰惩罚均值/步 |
| `blue/rate_collision` | BLUE 窗口自碰率 |

### 运行命令

```bash
cd PythonAPI/examples/mappo_training

# 基础起步
python -m training.train_multi_adversarial_kl_risk \
    --pretrained-ckpt logs/robust_v2/best.pt \
    --num-cooperative 2 --num-adversarial 2 \
    --beta-kl 0.1 \
    --threat-coef 2.0 \
    --target-blue-collision-rate 0.05 \
    --updates 30

# TensorBoard
tensorboard --logdir logs/multi_adv_kl_risk/tb_logs

# 续训
python -m training.train_multi_adversarial_kl_risk \
    --pretrained-ckpt logs/robust_v2/best.pt \
    --resume latest \
    --save-dir ./logs/multi_adv_kl_risk \
    --updates 100
```

## 2026-06-09 续训补丁

修补 KL-risk 脚本初版续训缺失的两处：

1. **`curriculum_success_history`**：v2 有保存恢复，新脚本初版漏写。
   不补会导致续训后场景"难易等级"重置，加权采样从零摸索。
2. **RNG state**：补 `torch.get_rng_state() / np.random.get_state() / random.getstate()`
   尽力恢复（被 try/except 包住，失败也不影响训练）。

修改位置：`_build_ckpt_dict` 新增 4 个键、resume 块新增对应恢复逻辑。
