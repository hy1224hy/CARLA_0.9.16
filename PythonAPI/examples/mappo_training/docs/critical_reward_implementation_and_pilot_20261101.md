# 危险交互奖励实现与弱红方蓝车先导（2026-11-01）

状态：**第一候选R1已完成真实训练及冻结评估，尚未达到正常驾驶与新增危险交互的联合目标；旧奖励R0完成训练，服务器重启后在新目录继续冻结对照评估。**

用户明确要求固定弱红方，训练蓝方使红方表现更差，并在后续澄清允许 C1 检查失败条件下继续工程训练。资格门槛保持原值，失败结果保留。本实验不恢复基础训练，不宣称红方或蓝方正式驾驶合格。

## 实现

- 新 profile：`critical_interaction_team_v1`。复用现有 C1 进度相对项、进度势差、风险/操纵成本、事件成本及真实退场尾项。
- 新危险项基于实际车辆 bbox 的固定朝向、匀速 OBB-TTC；中等风险带内给反馈，每回合最多5分；接触/极低TTC抑制全队当步正信用。出生保护、蓝方资格锁定、当前合法前向及动态前后关系共同限制正信用。
- 红车成功避让后仍可产生危险奖励；碰撞、越界、道路违规和任务违规不成为正奖励。后置蓝车可在超越后获信用，直接追尾不给正信用。
- 恢复自由行驶低速成本；记录危险、严重风险、低速、舒适、事件等分项及实际驾驶质量。
- 新质量字段可用于 Mut 教师门控和模型选择，缺测不能以部分样本平均后冒充完整质量。当前先导为B0，互学习关闭；不能将此结果称为B1/B2效果。
- 新场景版本保留原24例/划分、四方向及完整左右镜像。原基础走廊坐标恢复，后置距离8米，前置距离依划分10/11/12/13米；全部96例通过本地 OpenDRIVE 生产 resolver。
- 俯视跟随开启。临时 spectator 观察进程已在第一轮检查结束后退出；其没有 tick/reset。后续由现有环境自身跟随 spectator。
- C1 `lane_pid_v1` 为固定普通车道跟随及跟车基线，使用 CARLA 仓库自带 PID；只用于C1。C2始终使用蓝方Actor，未加入该控制器。

主要文件：`environment/mut_mappo_critical_reward.py`、`environment/mut_mappo_env.py`、`environment/frozen_lane_traffic.py`；对应配置、运行、统计、选择入口同步适配。`utils/critical_reward_pipeline.py` 串行调用已有参考生成、训练 supervisor 和独立危险评估，不重写PPO或检查点框架。

## 当前训练协议

实验目录：`experiments/adversarial_u1000_critical_reward_20261101_v3`。

红0/1固定u1000及SHA `0ac714a5172621cb1b716604bd69dd3a32dfaa57d5e44678eae7815195d6981a`，不进优化器。蓝2/3 Actor更新，使用新的四车Critic、ValueNorm和优化器。

外层seed42，B0，A/B两学习器；R1新奖励和R0当前效率奖励各24000实际train world ticks，包含训练阶段setup，按完整A+B边界停机并记录超量。A/B不是两个独立训练seed。

串行顺序：R1参考→R1蓝车训练→R1冻结gate评估→R0参考→R0蓝车训练→R0冻结gate评估。每组参考为train/gate/selection共72例×2次；因两种reward profile绑定不同参考身份，保守重新执行，合计288个C1参考回合。没有伪造另一profile的真实结果或参考身份。

参考生成显式使用 `--allow-weak-red`，授权及来源保存在 `control/training_authorization.json`；失败C1仍保留不合格标记。正式资格与red_screen阈值没有修改。该开关用于用户确认的工程诊断，不代表放行正式比较。

每组固定预算末评估24例×C0/C1/C2×A/B=144回合。两奖励均使用相同C1控制器、案例和配对seed。报告原始/合格危险、资格变化、TET/TIT、红方效率与任务完成、蓝方驾驶与违规。C1已存在危险或红方失败时，明确说明地板/天花板效应；不能把仅资格变化冒充新增攻击。

不使用test调奖励，不根据回报挑最好中间点。训练使用既有supervisor，核对launch_id及实际trainer PID与正常退出；source、配置、curve和checkpoint均绑定SHA。20分钟监控只读文件；额度接近上限时保存恢复状态并安排5小时后本对话续做，不重复启动已存活worker。

## 结果

R1固定末点A/B各24例：原始危险12/6例，事件资格危险6/3例，蓝方事件资格12/15例；C1分别23/6/7例。R1没有增加相对C1的事件资格危险，并且仍有速度、车道和操纵稳定性缺口，故当前不支持奖励有效性主张。A/B仍不是独立外层seed。事件资格也不等于完整正常驾驶资格。

R0原冻结评估29/144后客户端原生异常0xC0000409。retry1因服务RPC超时而被停止；用户重启CARLA后，版本和空闲只读检查通过，retry2在新目录继续。失败attempt不混入配对效果，已提交world ticks作为失败成本下界单列，中断构造/清理可能未被持久记录。训练检查点保持不变，无需重新训练。完成标记绑定最终报告SHA，分析工具据此定位有效报告，不再固定读取首次失败目录。
