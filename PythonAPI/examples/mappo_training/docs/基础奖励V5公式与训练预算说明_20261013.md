# 基础奖励V5公式与训练预算说明

日期2026-10-13，Asia/Shanghai。用户询问当前奖励与新训练update是否偏少。本次核对公式/实际checkpoint，未修改训练源码、未启动长跑。本文预算是下一步工程建议，不是已批准正式预算或收敛保证。

## 当前奖励

这是双红基础MAPPO奖励，没有蓝方对抗收益或Mut KL。每车独立结算进度与成本，团队评估要求两车正常完成；没有速度差或同步到达奖励。步长dt=0.1秒，gamma=0.999，p为路线完成比例。

| 项 | 公式/数值 | 意图 |
|---|---|---|
| 路线进度 | 20×(gamma×p_next−p_current) | 以完成任务为正信号 |
| 成功 | 合法目标框到达+20 | 完成激励 |
| 安全/道路终止 | 碰撞、越界、持续道路违规分别−50，按终局优先级而非全部重复叠加 | 安全与合法底线 |
| 超时 | −10−10×remaining_route_fraction | 未完成代价 |
| 即时效率 | −0.5×dt×clip((v_ref−max(0,v_forward))/v_ref,0,1) | 代替历史累计进度欠账 |
| 超速 | e=max(0,(v_kmh−15)/15)，cost=−dt×(0.5e+0.5e²) | 超速持续增长，无30km/h封顶 |
| 参考车道偏离 | u=max(0,(d_lateral−0.35)/0.9)，cost=−0.1×dt×(u+u²) | 较大偏离持续增长，无1.25米后封顶 |
| 其他保留项 | 纵向/转向控制变化、接近障碍、TTC、非法跨线 | 平滑及交互安全反馈 |

远目标v_ref=2.5m/s(9km/h)，距目标<=5米改为0.5m/s(1.8km/h)，这只是慢行参考，不等于已经成功。目标外停车仍扣费；起步2秒、前车受阻、复杂交互和终局仍豁免效率项。15km/h为当前候选任务偏好上界，不是道路法定限速声明。

合法换道宽限保留；非路口已有明确道路违规/反向邻道证据时取消车道成本的宽限，不改变终止条件。车道距离取road_reference_waypoints，不把驶入的反向邻道当作新安全中心。

数值例子：停车且不豁免时每步−0.05；30/50km/h超速成本约−0.10/−0.389每步；偏离1.25/2.5米车道成本约−0.02/−0.081每步。成本只是优化偏好，不是物理硬约束或安全保证。来源为environment/base_reward_v4.py、base_reward_v5.py、instant_pace_reward_v3.py/v4.py/v5.py。

## 5个updates能判断什么

每update采集16个联合双车回合，PPO5epochs重复同一批数据。5updates只有80个新回合，12固定案例平均约6–7次，且碰撞/违规可提前结束，真实有效transition数各车不同。不能把5epochs算成25次新环境采样；同updates也不自动等于同实际ticks/有效样本。

源u456是旧任务已形成的策略。当前V5完整继承Actor、Critic、optimizer、ValueNorm、RNG、课程及LR/entropy相位。实际u461 Actor LR约8.1135e−5，低于初始3e−4；熵系数约0.00309；ValueNorm beta=0.99999，旧回报统计保持。5次更新同时承担价值目标适应与行为微调，不能期待足以收敛。

解释纠正：短试验可确认新成本是否实际生效、记录/恢复是否正确、发现近目标豁免等明显设计缺口，也可判断“当前checkpoint还未达到驾驶要求”；它不能证明奖励无效、收敛失败或版本优劣。V2的20updates也只是短适应窗口，V2与其他5update版本预算不同，不能公平排名。此前频繁切换版本不应继续作为效果评价流程。

[MAPPO原论文](https://arxiv.org/abs/2103.01955)研究了PPO实现和超参数因素对经验性能的影响；没有给本CARLA任务的统一收敛轮数。下述50/100是按当前代码和吞吐设计的观察预算，不是论文标准。

评价逐车完成、安全、起步、速度、车道/错误方向、近目标停滞以及Critic拟合/策略KL，不能只看训练return。训练停止后再独立评估，最终留出案例不用于调参。若50–100曲线无持续改善，再定位确定性控制、观测和学习状态适应；不同时调整奖励、网络、学习率与课程。
