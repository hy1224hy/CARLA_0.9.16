**支持对比实验的重构应保持小而明确。** 建议先形成下列边界，不必先迁移到大型框架，也不必另写一个 v3 完整脚本。

- `PolicySpec + PolicyAdapter`：声明观测、动作、角色和网络结构；统一冻结 checkpoint 加载、确定性/随机动作和环境动作映射。适配器覆盖 MAPPO、IPPO、规则控制器；恢复训练仍要求完整训练状态严格兼容。
- `EnvSpec + ScenarioSpec`：集中管理地图、时间步、角色、任务边界、观测、安全和场景分布。把奖励版本、观测版本、动作版本分开声明；比较训练奖励时使用共同的任务/安全评估口径。
- `Collector + Learner`：复用采样、agent-specific 边界、GAE、归一化和 PPO 更新。MAPPO/IPPO 的差异集中在 critic 输入；共享/独立 Actor 的差异集中在 policy factory，不复制训练循环。
- `Evaluator + ExperimentMatrix`：一份 episode 明细格式支撑 C0/C1/C2、留出对手和结果汇总。配置生成完整变体后再做哈希与冻结，正式运行继续禁止临时覆盖。
- `RunRegistry`：保留现有 RunID、代码/场景指纹和中断记录，并区分“运行完成”“评估完成”“能力通过”。批量实验给每个 CARLA 实例独立端口和唯一 tick 控制者；同一同步 world 不承载两个并行训练客户端。

验收目标是：新增一个训练 seed、一个奖励变体或 IPPO 基线，主要通过配置/learner 差异完成；同一个冻结 Actor 可以进入基础评估、单蓝对抗和策略池评估，不再手动拼维度、映射和字段。依赖版本应保存实际环境快照，当前宽泛的最低版本 requirements 不足以独立重建实验环境。

**实验设计最值得保留的是 C0/C1/C2 与独立选模，但要补齐以下控制。** 当前研究不变量已经规定配对 `AttackEffect = SR(C2)-SR(C1)`，负值代表学习型对抗使成功率下降；`TrafficEffect = SR(C1)-SR(C0)` 单独报告。参见 [研究不变量](D:/study/yan2/CARLA_0.9.16/PythonAPI/examples/mappo_training/docs/毕业课题_研究推进TODO.md:61)。

1. C1 与 C2 固定相同车数、出生位置、初速度、车辆控制边界、地图及事件语义，仅替换背景车辆策略。做 M=1/M=2 比较时，各 M 都有对应 C1；否则车辆数量效应与协同学习效应混合。
2. 明确区分训练集、选模/池筛选 probe 集、最终测试集。当前 Road43/6 是选模验证集，不是未使用的最终测试集；C0 profiles 只有 smoke/gate/validation。见 [验证集用途](D:/study/yan2/CARLA_0.9.16/PythonAPI/examples/mappo_training/configs/evaluation/p0_base_c0_town05_r7_v5.json:121)。最终测试必须包含未参与调参/池筛选的初态扰动和对手；同镇其他直道只支持有限域内泛化。
3. 多个评估 seed 不自动等于多个不同驾驶场景。固定初态、确定性策略下，重复执行主要检验重放稳定性；应显式生成并冻结初始间距、速度和路线扰动，记录实际实现值。
4. 训练算法比较首先对齐环境交互预算，同时报告 active-agent transitions、优化步数和墙钟；种群方法计入所有候选策略训练、payoff 估计与筛选预算。相同 updates/episodes 不等价于相同成本。
5. 至少以 3 个训练 seeds 开发验证，最终主结论争取 5 个；它们是重复单位，不能把一个 checkpoint 的大量 episodes 当大量独立训练实验。按 seed/场景分层、保留 C1/C2 配对关系估计 95% 区间；样本量随 pilot 方差和最小关注效应确定。少数运行应报告不确定性，见 [Agarwal 等，NeurIPS 2021](https://proceedings.neurips.cc/paper/2021/hash/f514cec81cb148559cf475e7426eed5e-Abstract.html)。
6. 旧计划“每对 5 episodes 统计 power 足够”不成立；更晚计划的 40 回合也不是普适充分。举例，在独立同分布伯努利假设下，40 次零碰撞的单侧 95% 上界约为 `1-0.05^(1/40)=7.2%`，不能证明碰撞率低于 5%。
7. 安全约束与攻击效果同时报告。合法且非碰撞的攻击成功数量以全部试验为分母；可另报条件指标，但不能筛掉自撞/违规回合后只在幸存子集宣称总体有效。碰撞对象识别支持事件分类，不自动证明交通责任或反事实因果。
8. 只训练蓝车只能证明攻击效果。要声称提高鲁棒性，需要实际训练/微调红车，再在冻结的未知攻击者和正常 C0/C1 上验证改善与遗忘；同一训练对手上的胜率提高不够。

推荐把论文主问题收敛为：**在相同安全门槛、池规模和总预算下，按攻击效果互补性保留的对手策略，能否比单一最强策略、随机策略池和均匀池训练，提升对未见驾驶策略的合法攻击覆盖，并提高被训练驾驶策略在未见对手下的鲁棒性？**

潜在方法是先做行为合法性/自撞率筛选，再用独立 probe 上的 payoff 向量衡量互补性，限制冗余策略入池，并在训练中采样这些对手。这只是候选设计。它需要明确的选择规则、与已有多样性方法的区别和消融结果；增加一个距离公式、混合熵或有效秩指标不会自动构成创新。参数/seed 多样性应与行为和失败模式多样性分开。

对于毕业课题，该方向配合严谨对照可形成有价值的系统与实证贡献；对于更强的方法论文，还需要证明所提筛选/约束机制提供可重复、预算公平、跨对手的独立增益。现有工程修复应放在实验可信性与实现章节，PSRO、MAPPO、通信不宜堆成三个尚未验证的创新点。

**建议的最小实验矩阵要分开检验“池选择”和“混合方式”。** 先用一个合格红方基线、一个蓝车，冻结共同 MAPPO/PPO 内核。完整横评 SAC/TD3/MADDPG 暂无必要；若论文主张集中 critic 的协作价值，再增加 IPPO 对照。

| C0 / C1 / 单蓝 C2 | 无背景、普通背景、学习型背景 | 学习攻击是否超出普通交通效应 |
| 固定候选集：单一最强 / 均匀混合 / PSRO 元混合 | 混合权重规则 | 元策略是否比普通对手随机化有价值 |
| 固定混合规则：随机选池 / 行为距离选池 / payoff 互补选池 | 同样大小的池如何选成员 | 候选创新的池选择机制是否有独立价值 |
| 完整方法去掉安全筛选；完整方法去掉互补筛选 | 每次去掉一个机制 | 收益是否由约束或互补机制带来；始终使用共同安全测试 |
| 红方无对抗微调 / 普通交通微调 / 最强单对手微调 / 池微调 | 相同预算下的训练对手分布 | 是否改善未知攻击下鲁棒性，正常驾驶是否退化 |

先完成 C012 的攻击有效性检查，再开展小规模池比较，最后对选定方法做消融与红方加固。比较时固定生成候选的总成本，报告筛选成本；共同候选集的离线筛选可先提供便宜的机制证据，在线扩池优势须另外验证。最终测试不得参与 payoff 筛选。若声称接近均衡，需要额外训练未入池的响应策略估计可利用性；有限矩阵求解及低 JPC 均不能保证全策略空间的 Nash 收敛。

**后续优化路线按验收产物推进。** 下表给的是建议，不改变仓库原有冻结门槛，也不将本次已看过的训练结果作为预注册测试结果。

| 顺序 | 实际工作 | 进入下一步所需证据 |
|---|---|---|
| 1. 补上 R8 评估 | 支持最新 checkpoint；在开发评估中冻结若干 u60/u80/u100 候选，比较确定性动作与随机动作；分镜像、分 agent 输出轨迹、成功、安全失败 | 明确当前成功能否在独立执行下保持，以及主要失败来源；另保留未看的 final-test |
| 2. 稳定最小驾驶能力 | 以脚本/PID 全控制作任务可达性对照；必要时用 PID 转向 + 学习纵向、或单 agent/冻结同伴做机制诊断 | 短路线滚动/静止起步与留出镜像通过既定能力门槛，再进入长路线、跟车、并道 |
| 3. 只改被证据支持的因素 | 若确定性显著更好，优先检验探索/转向噪声；若确定性也差，检查控制/路线观测与奖励排序；每次一个主变量 | fresh、等预算、小规模多 seed 对照；不能只看训练 return 或单个 best checkpoint |
| 4. 统一单蓝链路 | PolicyAdapter、环境/生命周期一致性、碰撞对象分类、统一 C012；可用规则红车辅助排查 | 在合格冻结红方上有安全约束下的配对攻击效果，工程与效果均通过 |
| 5. 形成小池方法闭环 | 先比较 single/uniform/互补池，随后按需要补元求解器；对红方做同预算加固并测试未知对手 | 贡献可由消融归因，同时保持正常驾驶能力 |
| 6. 扩展 | 双蓝与同车数对照、完整双边响应、更复杂地图；通信最后作为可选扩展 | 前面主结果已稳定，扩展服务于明确论文假设 |

不建议把基础驾驶从零训练无限延长成第二个主课题。可给修复路线设置预先约定的诊断预算；若在预算内仍无法稳定形成合格红方，则采用行为克隆初始化或规则规划器加低层控制先完成攻击研究闭环，所有相关方法使用同一基础条件，并把从零学习列为单独对照。R8C1 已出现正向结果，当前应先评估它，再决定是否需要这些替代路线。

本次审查最直接的三个待办是：**实现 R8 独立评估；统一最新 Actor 到单蓝入口的协议；冻结一个小规模、预算公平的策略池对照。** 新奖励、更大网络、更多蓝车和通信应由这些证据决定是否投入。
