## 3. 减速暴露既有横向接近风险

V3 SC01第23步，两车collision_event均1。横向间距约2.02m；基线同刻也有几乎相同横漂。因此不能写成“V3才产生横漂”或认定共享Actor trunk是原因。基线纵向领先2.237m，V3仅1.440m；中心距3.015→2.481m，减速后已有横向接近遇到更小纵向分离。

当步双方road_success_eligible仍1，TTC成本均0；agent0车道偏离1.2125m，成本−0.009583接近−0.01封顶；agent1 lidar风险成本仅约−9.08e−6。这说明道路合法/纵向TTC不充分描述侧向接触风险。是当步证据，不把单步量级比当完整回报支配证明。trace未保存other_actor身份/类型/impulse，不能法证确定碰撞对象或责任。

建议候选：对普通直路任务复查车道边缘安全裕度与侧向/斜向接近，考虑更有区分度的车道偏离或身体间距风险成本，并保留合法并线任务的单独处理。先查现有20D射线是否能及时提供相关信息；必要时才增加执行可获得的相对运动/车道信息并升级协议。不要用强制两车速度差或到达同步来解决接触，也不盲目冻结一个本来已有横漂的转向策略。

## 4. 慢车起步与部署方式须单独检查

SC11静止场景，u456 agent1第1步就输出刹车约0.121；V3升至0.157。其后虽然开始小油门，但实测速度持续接近0，首次运动从4.4推迟5.7秒。V3第30–50步有效油门约0.15–0.17仍未形成有效起步。均值纵向动作更弱是观察事实，不能直接断定物理最小油门阈值或传动bug。

训练采用Gaussian采样，部署/当前评估采用确定性均值；agent1 pre-tanh log_std约−0.49。这提示训练可能借随机较大油门起步而均值策略仍刹车/小油门，需要一次随机/确定性部署诊断确认，不能用随机表现替代已定的确定性红策略验收。

候选优化：在无前车、未到达、非合法让行的起步/低速状态给予一致前进反馈，检查动作死区/车辆实际控制/传动响应；必要时用少量正常起步示范辅助初始化均值策略。避免普遍加大低速罚款催促危险跟车。起步示范或新辅助损失目前未实现，不能给虚构CLI。

## 5. 当前奖励的判断与下一步

当前保留进度、到达、碰撞/越界/合法性骨架有合理动机，但V2/V3的整体权衡未通过正常驾驶目标。优化优先级：

1. 先关闭近终点未完成停车的豁免缺口；V4已实现并离线通过。
2. 复核SC01的侧向接近与转向振荡，再决定车道/接近风险反馈；不要继续只调超速系数。
3. 单独定位确定性起步能力，合理跟驰/让行仍要豁免。
4. 检查新奖励下的逐车Critic拟合、ValueNorm尺度及策略更新幅度；完整继承旧学习状态是本轮工程选择，不证明已适应新目标。重置/先适配Critic需另立实验，不伪装原run严格恢复。
