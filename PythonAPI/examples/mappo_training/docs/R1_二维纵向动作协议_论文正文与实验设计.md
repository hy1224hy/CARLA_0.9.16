# R1 二维有符号纵向动作协议：论文正文与实验设计

> 适用范围：基础 MAPPO 当前入口、动作协议 v2、checkpoint/指标协议及基础策略 C0 evaluator。
> 研究边界：本节不修改奖励函数、集中式 Critic、观测、场景或 PPO 超参数，也不把离线回归通过表述为 CARLA 性能已经改善。
> 论文使用建议：第 1—5 节可直接纳入“车辆动力学与动作空间设计”；第 6—8 节适合放入“实现细节、实验协议与有效性威胁”。

## 1. 问题来源与修改动机

本研究首先采用三维连续动作

\[
\mathbf{u}^{(1)}_t=(a^T_t,a^\delta_t,a^B_t)\in[-1,1]^3,
\]

分别表示油门隐变量、转向和制动隐变量。为满足车辆不能同时施加有效油门和制动的控制约束，旧协议先将两个纵向隐变量线性变换到 \([0,1]\)，再以 winner-take-all（WTA）规则选取较大者：

\[
\tilde T_t=\frac{a^T_t+1}{2},\qquad
\tilde B_t=\frac{a^B_t+1}{2},
\]

\[
(T_t,B_t)=
\begin{cases}
(\tilde T_t,0), & \tilde T_t\ge \tilde B_t,\\
(0,\tilde B_t), & \tilde T_t<\tilde B_t.
\end{cases}
\]

该映射能够保证 \(T_tB_t=0\)，但存在三个与学习效率直接相关的问题。

第一，两个策略维度共同描述一个纵向自由度，形成多对一的冗余参数化。环境只执行获胜踏板，另一个维度虽然进入策略概率，却不产生对应的物理控制量，使纵向信用分配变得间接。

第二，WTA 在 \(\tilde T_t=\tilde B_t=c>0\) 处不连续。当两个隐变量仅发生无穷小的相对次序变化时，执行动作会在 \((T,B)=(c,0)\) 与 \((0,c)\) 之间切换，其跳变量为 \(\sqrt{2}c\)。因此，相近的策略样本可能产生性质相反的驱动/制动命令。

第三，神经网络均值为零并不对应车辆滑行。当 \(a^T_t=a^B_t=0\) 时，旧协议得到 \(\tilde T_t=\tilde B_t=0.5\)，并因平局规则执行半油门。这使策略分布中心带有非零纵向驱动偏置，滑行反而需要两个隐变量形成特定组合。

R0 诊断进一步给出了工程触发证据：训练后期随机动作的制动模式持续上升，update 10 的两次确定性 C0 评估均表现为两车全程制动、16/16 超时。该证据不能单独证明 WTA 是制动塌缩的唯一原因，因为奖励预算和 Critic 拟合仍有独立问题；但它足以否定“继续沿用旧动作协议且直接延长训练”的方案。因此，R1 仅隔离修改动作参数化，其余研究变量保持不变。

## 2. 车辆动力学层面的理论依据

在低侧滑、常规道路速度条件下，车辆平面运动常用运动学自行车模型描述 [1]。令车辆质心位置为 \((x,y)\)，航向角为 \(\psi\)，纵向速度为 \(v\)，轴距为 \(L\)，前轮转角为 \(\delta\)，纵向加速度为 \(a\)，则一种常用表达为

\[
\dot x=v\cos\psi,\qquad
\dot y=v\sin\psi,
\]

\[
\dot\psi=\frac{v}{L}\tan\delta,\qquad
\dot v=a.
\]

该模型的控制自由度天然可写成

\[
\mathbf{u}=(a,\delta),
\]

即一个有符号纵向控制量与一个转向控制量。正的 \(a\) 表示驱动需求，负的 \(a\) 表示减速需求。需要强调的是，本项目的 `signed_longitudinal` 是归一化纵向控制需求，而不是以 \(\mathrm{m/s^2}\) 为单位、经过标定的真实加速度；其物理执行仍由 CARLA 的油门和制动接口完成。

采用“加速度/纵向需求 + 转向”的学习动作并非孤立设计。Folkers 等使用 PPO 学习加速度与转向命令，并在仿真和全尺寸研究车辆上进行了验证 [2]；Maramotti 等的深度强化学习规划器同样预测加速度和转向角，并讨论了仿真到真实车辆动力学的迁移 [3]；Song 和 Lin 在多车辆交互控制中直接以加速度和转向角作为车辆控制量，并在多车场景中验证交互行为 [4]。这些工作支持二维纵向—横向控制分解的合理性，但不意味着任何具体死区宽度都由文献唯一确定，也不保证本项目的 MAPPO 必然收敛。

另一方面，直接输出油门、制动和转向同样可以构成合法的强化学习动作空间。R1 的理论主张不是“三维控制在一般情况下错误”，而是：对本项目已经观察到的 WTA 冗余、切换不连续和零均值偏置，二维有符号纵向参数化是更匹配车辆纵向自由度、且可由对照实验检验的修复假设。

## 3. 动作协议 v2

Actor 的动作改为

\[
\mathbf{u}^{(2)}_t=(\ell_t,\delta_t)\in[-1,1]^2,
\]

其中 \(\ell_t\) 为有符号纵向需求，\(\delta_t\) 为归一化转向命令。为给策略提供稳定、显式的滑行区间，定义中心死区 \(d=0.05\)，并使用连续重缩放函数

\[
g_d(\ell)=
\begin{cases}
\dfrac{\ell-d}{1-d}, & \ell>d,\\[6pt]
0, & |\ell|\le d,\\[6pt]
\dfrac{\ell+d}{1-d}, & \ell<-d.
\end{cases}
\]

最终发送给 CARLA 的三通道动作为

\[
T=\max(g_d(\ell),0),\qquad
B=\max(-g_d(\ell),0),\qquad
S=\delta.
\]

该映射具有以下性质：

1. **范围有界**：\(T,B\in[0,1]\)，\(S\in[-1,1]\)；
2. **纵向互斥**：任意输入下均有 \(TB=0\)；
3. **中心可滑行**：\(|\ell|\le d\Rightarrow T=B=0\)；
4. **边界连续**：在 \(\ell=\pm d\) 两侧函数值均趋于 0，不再出现 WTA 的有限跳变；
5. **符号对称**：\(g_d(-\ell)=-g_d(\ell)\)，驱动与制动具有对称的归一化幅值；
6. **保留全控制幅值**：\(g_d(1)=1\)，\(g_d(-1)=-1\)。

死区外斜率为 \(1/(1-d)\approx1.0526\)，因此死区不会牺牲端点控制范围。\(d=0.05\) 是本研究在 R1 前冻结的工程参数，用于隔离动作协议变量；它不是从上述论文直接抄录的经验常数。若后续比较不同死区宽度，应另行注册消融实验，不能根据正式 pilot 结果事后调整。

## 4. PPO 概率口径与确定性评估

每个智能体的 Actor 输出二维对角高斯分布参数。令

\[
\mathbf z_t\sim\mathcal N(\boldsymbol\mu_\theta(o_t),
\operatorname{diag}(\boldsymbol\sigma_\theta^2)),\qquad
\mathbf u_t=\tanh(\mathbf z_t).
\]

对 tanh 压缩后的有界动作，采用变量变换修正后的对数概率 [6]：

\[
\log\pi_\theta(\mathbf u_t|o_t)
=\sum_{j=1}^{2}\log\mathcal N(z_{t,j};\mu_{t,j},\sigma_{t,j})
-\sum_{j=1}^{2}\log\left(1-\tanh^2(z_{t,j})+\varepsilon\right).
\]

PPO 仍按 Schulman 等提出的裁剪概率比目标更新策略 [5]：

\[
r_t(\theta)=
\exp\left[
\log\pi_\theta(\mathbf u_t|o_t)
-\log\pi_{\theta_{\mathrm{old}}}(\mathbf u_t|o_t)
\right].
\]

实现中直接在 rollout 保存二维 pre-tanh 样本 \(\mathbf z_t\)，更新时用同一个 \(\mathbf z_t\) 重算新策略对数概率，从而避免通过 `atanh` 反推带来的数值误差。死区与油门/制动拆分是采样之后的确定性环境适配，不额外进入 PPO 的概率密度，也不在三维物理动作上伪造 log-prob。策略参数未更新时应严格满足 \(r_t=1\)。

C0 评估不采样探索噪声，而使用

\[
\mathbf u_t^{\mathrm{C0}}=\tanh(\boldsymbol\mu_\theta(o_t)),
\]

随后调用与训练完全相同的动作协议 v2 映射。这样，训练、PPO 概率审计和确定性评估共享同一个二维策略语义。

## 5. 对更多车辆的适配性

动作协议是逐智能体的局部适配器。对 \(N\) 辆同构学习车辆，第 \(i\) 辆车独立执行

\[
(\ell_i,\delta_i)\mapsto(T_i,S_i,B_i),\qquad i=1,\ldots,N.
\]

因此车辆数量增加时，单车 Actor 的输出宽度仍为 2，动作适配器本身不需要随 \(N\) 改写；系统只需在按 `agent_id` 索引的动作字典中增加车辆。该性质也避免了用全局 \(2N\) 维联合 Actor 直接控制所有车辆。

不过，当前 R1 训练契约和 C0 契约仍冻结为两车。扩展到更多车辆时，联合状态长度、AgentConditionedCritic 的 `num_agents`、场景 schema、生命周期证据和 C0 case 都必须升级版本。这些属于多车实验协议与 Critic 输入结构变化，而不是 signed-longitudinal 映射自身的限制，不能在 R1 中隐式完成。

## 6. checkpoint、旧权重与指标兼容性

| 对象 | R1 规则 |
|---|---|
| 新训练 | Actor 明确构造为二维输出；正式契约要求 `source_mode=fresh`，禁止 pretrained |
| PPO rollout | 保存二维 `action_z`、二维 tanh 策略动作和对应标量 log-prob |
| CARLA step | 只接收映射后的三维 `[throttle, steer, brake]` |
| R1 checkpoint | schema v3；必须保存完整 `action_spec`、二维 `model_spec.action_dim` 及动作/指标协议版本 |
| R0/WTA checkpoint | Actor 输出头、`log_std` 和 optimizer state 的形状均不兼容；禁止 R1 strict resume 和正式 pretrained |
| 历史证据 | v1 checkpoint、C0 episode 和 metrics 仍可通过显式 legacy 协议离线读取/验证，不被重写 |
| C0 v2 | 记录二维策略均值/死区率/饱和率，同时保留 CARLA 三通道均值与模式率；二者映射不一致即拒绝证据 |
| Critic | R1 不改变 Critic 类型、参数、输入维度或更新目标 |

共享 `Actor` 类保留可配置的 `act_dim`，以免破坏仓库中的历史三维入口；当前基础训练和 C0 v2 必须从版本化契约显式取得二维动作宽度。兼容性由 checkpoint header、`action_spec`、`model_spec` 和严格 `state_dict` 加载共同保证，不允许以 `strict=False` 静默复用旧输出层。

## 7. 可证伪假设与预期结果

R1 的核心假设是：在奖励、Critic、场景和 PPO 超参数不变时，二维有符号纵向动作可以消除 WTA 特有的冗余竞争、切换不连续和零均值半油门偏置，使滑行成为策略分布中心附近的显式可达模式，并提高纵向动作证据的可解释性。

预期的直接结果是动作协议不再产生油刹冲突，零纵向策略动作对应滑行，训练与 C0 可以同时审计策略空间和执行空间。预期但尚未由 R1 离线测试证明的行为结果包括：降低无意义的油门/制动模式切换、改善纵向探索效率，并减少由动作参数化诱发的局部最优风险。

R1 不承诺单独消除全程制动，也不承诺提高成功率。若新 pilot 仍出现制动塌缩，说明奖励预算或 Critic 拟合等后续假设仍需检验；这不会反向否定二维映射已经满足的数学不变量。

## 8. 测试计划与五项验收标准

### 8.1 测试计划

1. **动作数学单元测试**：覆盖端点、正负对称、死区内部、\(\pm d\) 连续性、批量输入、范围、NaN/Inf、错误维度和油刹互斥。
2. **Actor/PPO 测试**：检查 Actor、`action_z` 和 tanh action 均为二维；同一 pre-tanh 样本重算 log-prob 完全一致，更新前 ratio 等于 1；完整生产 PPO update 保持有限并更新模型。
3. **checkpoint 测试**：R1 payload/action spec 往返恢复；动作维度、协议或 spec 漂移立即失败；旧 WTA checkpoint 只能进入显式 legacy 离线诊断路径。
4. **训练与指标集成测试**：active-agent 采样只写有效二维样本；recorder 同时核对二维策略动作和三维环境动作；TensorBoard/JSONL schema、模式守恒、死区率和饱和率可由独立 validator 重算。
5. **C0 离线测试**：C0 v2 只接受二维 checkpoint，确定性 Actor mean 只推理一次并同时形成策略/环境证据；v1 历史 C0 仍可读取，但不能作为新正式执行契约。
6. **全量无 CARLA 回归**：运行全部测试、契约加载、Python 编译、静态旧维度扫描和 `git diff --check`。R1 明确不启动 CARLA。
7. **后续真实 smoke（不属于本次 R1）**：待奖励与 Critic 后续修复及 GO/HOLD v2 一并冻结后，由研究者重启 CARLA，再执行策略无关 action/reward smoke 和 1—3 update 工程 smoke。

### 8.2 R1 五项验收标准

| 编号 | 验收标准 |
|---|---|
| A1 动作语义 | `[-1,1]^2 -> [0,1]×[-1,1]×[0,1]` 映射有界、互斥、中心可滑行、在死区边界连续，训练与 C0 共用同一实现 |
| A2 PPO 一致性 | 采样、buffer 和 log-prob 全部为二维 pre-tanh 口径；未更新策略的概率比严格为 1，不对三维环境动作计算伪概率 |
| A3 兼容性 | checkpoint schema/action/metrics/C0 升级；R0 权重不能被 R1 resume/pretrained；旧证据只读且离线 validator 不退化 |
| A4 可审计性 | 每个 active agent 同时记录二维策略动作与三维执行动作，映射必须逐步一致；死区率、饱和率、油门/制动/滑行模式守恒 |
| A5 因果边界与回归 | reward 与 Critic 无代码变化、CARLA 不运行；动作专项、生产 PPO、checkpoint、metrics、C0 及全量无 CARLA 回归全部通过 |
