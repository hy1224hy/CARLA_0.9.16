# B2门控实现审查（2026-11-03）

结论：门控与PPO/冻结教师的连接基本正确，但当前指标只支持“事件资格危险”的选择性互学，不能把它称为完整正常驾驶门控。现有24k先导的门始终关闭，直接照搬预算很可能没有互学干预。建议先修正实验配置准备入口、登记教师质量定义，再串行做同一外层seed、同预算的B0/B1/B2工程比较。本轮未连接CARLA，实际world ticks为0。

## 现行规则与训练链路

对学生S、对方教师T、场景类别f，令N为该类别全部有效配对案例数，b为蓝方事件不合格率，q为事件资格危险率：

\[
g_{S\leftarrow T,f}=\mathbf1[N_S=N_T\ge8]\,
\mathbf1[b_T\le0.125]\,\mathbf1[b_T\le b_S]\,
\mathbf1[q_T-q_S\ge0.25].
\]

在当前critical模式，q=count(safe_critical_event)/N，即最终蓝方事件资格G乘以危险事件H。碰撞、越界、道路违规或任务违规会使G失败；q不是完整速度、参考车道、操纵质量合格率，也没有减去C1已有危险。

门按family开启，当前为blocking与cut_in；不是每个状态的安全过滤器。当前gate中blocking为8例，cut_in为16例。因此前者允许教师最多1个坏例、至少多2个资格危险；后者最多2个坏例、至少多4个资格危险。25个百分点是设计阈值，不是统计显著性检验。

Actor最小化的辅助项为：

\[
L_{\mathrm{mut}}=\frac{0.01}{M}\sum_{t=1}^{M}
 g_{S\leftarrow T,f(t)}D_{\mathrm{KL}}
 \big(\pi_S^z(\cdot\mid o_t)\Vert\bar\pi_T^z(\cdot\mid o_t)\big).
\]

z是tanh之前的二维高斯动作。分母保留全部有效Actor样本，关闭的样本贡献0。教师在学生自身采集的观察上给分布，按相同物理ID2/3对应；教师、红方Actor不接收该损失的梯度。A/B双方各有蓝2/3、自己的四车Critic、优化器、ValueNorm与RNG。

已经核对：A/B刷新前同时做冻结快照；固定gate案例分别评估，失效案例直接报错；统计绑定快照hash与version；set_peer再次验证Actor内容hash；教师eval并requires_grad=False；实际PPO minibatch加入该KL；门权重在一个rollout的各epoch中保持一致；断点包含门、教师和RNG。场景case_key通过runner的family_map进入正确family。
