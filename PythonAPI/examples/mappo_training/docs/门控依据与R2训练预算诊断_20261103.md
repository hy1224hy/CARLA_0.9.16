# 门控依据、参数来源与R2训练预算诊断

本次为文件核验和原始论文核对，不连接CARLA，不启动训练。结论：当前门控是有合理动机但尚未完成实证定标的场景族启发式；24k是排错先导预算，现有证据不能确定不合格由训练不足造成，也不能证明R2无效。

## 论文与实现的对应边界

1. [Dual Policy Distillation，IJCAI 2020](https://arxiv.org/html/2006.04061)：第3.2节讨论从不完美同伴中提取有益知识，基于状态价值优势选择蒸馏；考虑价值估计误差后，在式11/12改用指数加权。支持“有条件学习同伴”的动机。我们的场景族独立评估、事件坏率门槛、G×H指标及1/8、2/8阈值不是其公式或理论保证；我们也没有照搬其同伴数据采样方式。
2. [Safe Policy Improvement with Baseline Bootstrapping，ICML 2019](https://proceedings.mlr.press/v97/laroche19a.html)：在离线RL中，对高不确定性区域保留基线约束。它提供“证据不足时保守迁移”的方法论参照，不是当前B2的直接复现，保证不能迁移到本实现。
3. [The Surprising Effectiveness of PPO in Cooperative Multi-Agent Games，NeurIPS 2022](https://arxiv.org/html/2103.01955v4)：第5.3/5.4节和超参附录表明epochs、minibatch、clip等会影响学习，进行了任务相关定标。当前2 epochs、128样本minibatch等并非其完整配置复现；不能仅引用MAPPO就认定本项目数值已验证。

以上对当前设计的支持是方法动机层面的解释，不能写成“论文证明当前门控可靠”。也不需要先训练出全局完美专家才能研究互学；当前绝对安全准入是本项目的保守选择，会限制早期互学的启动。

## 门槛的实际来源

docs/MutMAPPO最小方法与对照实验规格_20261007.md第4节已写明：n≥8、教师b≤1/8且不高于学生、q差≥2/8，是小样本保守启发式，不是置信检验；2/8是为了避免单个案例波动决定学习方向。它不是从某篇论文得出的最优值。8例门槛和检查周期原本服务于小规模估时，不是已验证充分样本量。

该规则的合理部分：单列安全与攻击收益；按场景类别保留不同专长；共同案例、固定教师和完整分母，避免由不同案例或稠密回报尺度决定教师。

限制：类别均值不保证教师在学生实际状态上更好；每类8/16例离散性很强；保守硬门可能长期全关；G缺少完整速度/车道/操纵质量；G×H尚未扣除C1已有危险。坏例也包含被撞，不能等同违法或事故责任。当前只能称“事件资格及效果门控候选”。

## R2参数来源与含义

配置：experiments/adversarial_u1000_critical_reward_20261101_v4/configs/R2_B0_s42.json。

生成链：configs/mut_mappo/local_candidate_v1.json中已存在相同学习参数；10月29日互动实验base_config沿用；utils/critical_reward_pilot.py继承该base配置准备R0/R1；utils/prepare_critical_reward_v2.py继承v3的R1配置准备R2，并明确只改变奖励及登记的信用保护。未找到针对R2单独进行系统PPO参数搜索的证据。

| 项目 | R2实际值 | 依据与限制 |
|---|---|---|
| 蓝Actor初始化 | 固定红u1000角色0/1映射到蓝2/3 | 复用基础驾驶，不是全模型随机开始 |
| Critic/ValueNorm/优化器 | 新建四车状态 | 基础双车Critic等没有迁入 |
| 网络 | 两层128单元、Actor 20/2 | 既有公共实现，非R2架构搜索 |
| Actor/Critic初始学习率 | 各3e-4 | 沿用候选配置 |
| 学习率调度 | 3e-4×max(0.1,1−train_ticks/24000) | 同停止预算耦合，末期3e-5；不是衰减到0 |
| γ / GAE λ | 0.999 / 0.95 | 既有配置；奖励势函数/回报尾项与γ保持一致 |
| PPO | clip=0.15，epochs=2，minibatch=128 | 继承、偏少的数据复用，没有R2最优性证据 |
| 熵 / 梯度裁剪 / KL早停 | 0.01 / 0.5 / 0.02 | 继承的稳定更新设置，非本次专门定标 |
| 每队每次更新 | 4回合 | 单CARLA世界串行采样的先导配置 |
| 互学β / anchor β | 0.01 / 0 | 0.01原规格标为候选；R2为B0，互学项实际关闭；无anchor约束 |
| gate时钟 | warmup 10k，后每20k train ticks | 既有公平成本协议；24k先导实际只刷新一次 |
| 停机 | A+B合计24k实际train ticks、完整边界软上限 | 奖励排错/同预算比较，非收敛承诺；rounds=1000不是实际跑了1000轮 |

源代码实际在采样后、PPO更新前按当前train计数设学习率。更改train_tick_budget也会改变整条学习率曲线；不能直接改24000为72000后声称只改变数据量。

## 实际学习证据

R2完成43轮，每队172回合，A+B共344训练回合。训练边界24343 train ticks，cleanup再1，实际训练控制总成本24344；其中训练decision ticks为19856，内部gate validation另3497 ticks。每队24个训练case实际出现5–11次。A/B属于同一个外层seed42。

以下前12轮与最后12轮各48回合/队，都是随机采样训练表现，不是配对冻结评估，也不是独立训练重复：

| 团队 | 指标 | 前48回合 | 后48回合 |
|---|---|---:|---:|
| A | 蓝方事件坏率 | 77.08% | 66.67% |
| B | 蓝方事件坏率 | 56.25% | 37.50% |
| A | G×H | 18.75% | 14.58% |
| B | G×H | 31.25% | 18.75% |
| A蓝2 | 回合均速的均值m/s | 3.849 | 4.716 |
| B蓝2 | 回合均速的均值m/s | 4.463 | 4.779 |

同一gate清单的确定性快照：第19轮A坏15/24、G×H=5/24，B坏10/24、G×H=8/24；最终A坏14/24、G×H=5/24，B坏5/24、G×H=9/24。快照有改善，但只在有限案例/一个外层seed上成立。

优化日志：前12轮Actor近似KL均值在0.0012–0.0039，后12轮为0.000039–0.000141；后12轮clip fraction均值为0。前后这两个窗口都没有因target_kl提前截断2个epochs。小KL可由学习率衰减/梯度等造成，不能证明策略收敛；早停不是这些窗口更新不足的直接原因。Critic EV窗口均值约0.136提升至A0.180、B0.194，也不能单独作为充分收敛证明。

最终A的5个、B的9个G×H案例均未同时满足两蓝车既有超偏好速度比例≤5%的要求。危险事件减少且车速上升，与“更快通过、减少交互”的行为解释相容，但仍需轨迹核查，不能确认为因果机制。

## 可以得出什么，下一步怎么分辨

- 可以确定：教师事件指标未过当前规则，B2门重放关闭；R2/B0本身不使用互学，因此门控没有造成当前B0的不合格。
- 支持但不能确定：43轮/每模板5–11次较短，新四车Critic仍在学习，固定gate有所改善，追加训练值得测试。
- 尚不能区分：交互数据量不足、2 epochs/末期低学习率造成的更新不足、R2目标权衡不合适、初始化驾驶缺陷或有限case与seed造成的波动。

建议先做B0预算诊断，再投入三组对比。保持R2、红方、场景、评估协议及阈值固定，预先登记更长学习率时钟与预算，在24k/48k/72k记录冻结曲线。历史24k的学习率时钟不同，应作为历史参考，不能包装成纯预算对照。

若需要直接检查当前断点追加训练是否有效，可在新版本中从同一完整A+B边界接续，保留优化器/ValueNorm/RNG和谱系，显式固定学习率与新增预算；不能修改历史run身份后假称原样续训。后续同预算仅改学习率或数据复用的对照，可进一步区分采样量与优化强度。本轮只提出设计，没有启动、改奖励或修改门槛。

判据必须同时看坏率、原始危险、G×H、C1配对变化和完整驾驶质量。若坏率继续下降而G×H继续下降，需要检查回避交互/更快脱离等行为；若多次冻结曲线平台仍明显不合格，需要检查奖励/优化，不能无限追加训练。72k同样是下一阶段诊断上限建议，不是论文给出的足够收敛预算。
