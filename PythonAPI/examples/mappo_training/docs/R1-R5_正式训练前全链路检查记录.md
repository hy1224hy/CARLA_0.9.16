## 7. u5 后的强制停止顺序

1. 训练只到 u5，确认产生 immutable `periodic/ckpt_update_000005.pt`；
2. strict validator 对账 updates 1–5、每 update 16 episodes、PPO/ratio/TB/JSONL；
3. 用 C0 v4 对同一 u5 periodic checkpoint 跑主 gate；
4. 用新 EvalID 对同一 checkpoint 跑重复 gate，只用于离散重复性；
5. 用 GO/HOLD v2 生成唯一 u5 judge。u5 是第一个里程碑，不提供 `--previous-decision-report`；
6. 根据机器结论决定下一步。不得自动继续 u6–u10，也不得因训练 return 或视觉观感临时调参。

完整可复制命令已统一更新到 [`RUN_COMMANDS.md`](../RUN_COMMANDS.md)。只有 update 100 的 `PILOT_GO` 才能放行多 seed；u5 通过不等于基础 checkpoint 已可用于对抗训练。
