## 1. 整体架构

```
┌──────────────────────────────────────────────────────────────────┐
│                      CARLA 0.9.16 Server                         │
│              (Unreal 引擎，同步模式 dt=0.1s)                       │
└──────────────────────────────┬───────────────────────────────────┘
                               │ TCP 2000
┌──────────────────────────────▼───────────────────────────────────┐
│                  CarlaMultiAgentEnv（Town02 直道）                 │
│  · 找最长直道 → 分配起点/终点                                       │
│  · 每车挂载：RGB camera / collision / lane_invasion                │
│  · 19 维 obs（8 基础 + 11 lidar），3 维 action [thr, str, brk]    │
│  · reward_version 调度 v1 / v2                                    │
│  · goal_zone 矩形终点判定                                          │
└──────────────────────────────┬───────────────────────────────────┘
                               │ obs / rew / done
┌──────────────────────────────▼───────────────────────────────────┐
│              MAPPO (CTDE)  — 每个 agent 独立 Actor                │
│  · Actor: 2×128 Tanh + tanh-squashed Normal                       │
│  · CentralizedCritic: 输入拼接全局 obs                            │
│  · GAE + Clipped PPO + Entropy bonus + GradNorm                   │
└──────────────────────────────────────────────────────────────────┘
```

整套系统遵循 **CTDE**（Centralized Training, Decentralized Execution）：
- 训练时 Critic 看全局拼接状态
- 执行时每个 Actor 只看自己的 19 维观测

### 2.4 Step / Observation

[carla_multi_agent_env.py:835-996](../environment/carla_multi_agent_env.py#L835-L996)

- **Observation**（19 维）：
  - 8 基础：`dx/100, dy/100, dist/100, angle_diff/π, speed/30, throttle, steer, brake`
  - 11 lidar：`ray_dist / 4.0`
- **Action**：3 维 `[throttle ∈ [0,1], steer ∈ [-1,1], brake ∈ [0,1]]`，clip 后 `carla.VehicleControl`
- 已到终点的车强制刹车（`brake=1`），不接收新动作
- 每步末：保存 `prev_controls`（供 v2 的 jerk/steer_rate 惩罚使用）
- 每步末：重置碰撞/车道偏离事件 flag，避免重复惩罚

### 2.6 Done 判定

[`_check_dones`](../environment/carla_multi_agent_env.py#L1373-L1449)

- 进入 `goal_zone` 矩形 → 该 agent `done=True`，并对 TM 设置 `ignore_vehicles_percentage(100)`，让它停在终点不阻挡他人
- 任一 agent **严重碰撞**（collision 或压人行横道）→ 全员 done（episode 终止）
- 所有 agent 都到达终点 → 全员 done
- 超过 `max_steps` → done（截断，非自然终止 → v2 用 Critic bootstrap）

### 2.7 全局状态

[`get_global_state`](../environment/carla_multi_agent_env.py#L1556-L1560)：拼接所有 agent 的 19 维 obs → `19 × num_agents` 维向量，供 CentralizedCritic 使用。

## 3. 模型层 Actor / CentralizedCritic

文件：[models/actor_critic.py](../models/actor_critic.py)

### 3.1 Actor（[actor_critic.py:12-56](../models/actor_critic.py#L12-L56)）

```
obs (19) → Linear(128) → Tanh → Linear(128) → Tanh
                                              ├→ mu_head (3)
                                              └→ log_std (learned param, 3)

action = tanh(mu + std·ε)          (tanh-squashed Gaussian)
```

- `sample_action`：rsample → tanh，配套 log-prob 修正项 `-log(1 - tanh²)`
- `evaluate_actions`：反向求 z（atanh），重算 log_prob，用于 PPO ratio
- `get_deterministic_action`：评估期用，直接返回 `tanh(mu)`

### 3.2 CentralizedCritic（[actor_critic.py:59-73](../models/actor_critic.py#L59-L73)）

```
global_state (19×N) → Linear(128) → Tanh → Linear(128) → Tanh → Linear(1)
```

输出标量 value，所有 agent 共享同一个 Critic，但每个 agent 各自一份 Actor（**non-shared policies**）。

### 3.3 PerAgentCritic（[actor_critic.py:76-90](../models/actor_critic.py#L76-L90)）

仅用于 [`train_adversarial_ppo.py`](../training/train_adversarial_ppo.py) 的单 agent PPO，输入是单 agent 19 维 obs。

## 4. 奖励函数 v1 vs v2

由 [`_compute_rewards`](../environment/carla_multi_agent_env.py#L999-L1004) 根据 `reward_version` 调度。

### 4.1 v1 — 原始二元阶梯

[`_compute_rewards_v1`](../environment/carla_multi_agent_env.py#L1006-L1132)

| 分量 | 公式 | 值域 | 问题 |
|---|---|---|---|
| progress | `Δdist × 20` | 0~+40 | 仅依赖位移 |
| speed | `<1km/h: -0.1 / >25km/h: -1.0 / else: +0.1` | 三段阶梯 | 无梯度 |
| centering | `lateral<5cm: +0.5 / else: 0` | 二元 | 全或无 |
| yaw | `angle_diff<0.2rad: +0.1 / else: 0` | 二元 | 全或无 |
| collision | `-100` | 稀疏 | 缺中间风险信号 |
| lane_invasion | `-5` 统一 | — | 不区分线型 |
| step | `-0.05` | 固定 | 时间压力弱 |
| success | `+100`（goal_zone 内） | 稀疏 | 不区分快慢 |

### 4.2 v2 — 全连续梯度

[`_compute_rewards_v2`](../environment/carla_multi_agent_env.py#L1134-L1371)

11 个分量，所有"形状奖励"改为可导：

| # | 分量 | 公式 | 关键超参 |
|---|------|------|----------|
| 1 | **效率加权 progress** | `Δdist × 20 × (0.3 + 0.7·eff)`，`eff=min(speed/8, 1)` | `TARGET_SPEED=8 m/s` |
| 2 | **速度（高斯）** | `0.5 × exp(-(v-8)²/(2·4²))` | `SIGMA_SPEED=4.0` |
| 3 | **居中（指数衰减）** | `0.5 × exp(-lat²/(2·0.3²))` | `SIGMA_CENTER=0.3m` |
| 4 | **航向（余弦）** | `0.15 × (cos(angle_diff)+1)/2` | — |
| 5 | **平滑性（jerk + steer rate）** | `-0.05·|Δthr|/Δt`、`-0.02·|Δstr|/Δt` | `JERK/STEER_RATE_WEIGHT` |
| 6 | **LiDAR 安全距离** | 对每条射线 `d<0.5` 时 `-0.3·(0.5-d)/0.5` | `SAFE_THRESHOLD=0.5` |
| 7 | **TTC 前向碰撞风险** | 同车道前车 TTC<3s 时 `-2.0·exp(-ttc/1.0)` | `TTC_*` 五个常量 |
| 8 | **碰撞** | `-100`（含压人行横道） | — |
| 9 | **分级 lane_invasion** | `Broken:-1 / Solid:-5 / Curb:-10` | severity_map |
| 10 | **step** | `-0.05` | 同 v1 |
| 11 | **success + time_bonus** | `+100 + 50·(max_steps-step)/max_steps` | 鼓励快速到达 |

每步典型 reward 值范围 `+8 ~ +21`（正常前进），碰撞 `-100` 触发即结束。

> 详细推导见 [reward_optimization_plan.md](reward_optimization_plan.md)。

### 4.3 对抗智能体奖励

[`_compute_adversarial_reward`](../environment/carla_multi_agent_env.py#L1491-L1545)

```
adv_reward = 0.3·progress + 0.3·speed + 0.2·centering + 0.1·yaw
           + 0.3·jerk + 0.3·steer_rate + 0.3·safety_lidar + 0.5·ttc
           + 1.0·collision + 0.5·lane_invasion + 0.1·step
           + 0.3·success + 0.3·time_bonus
           + cutting_in_reward          # 1~3m 侧面近距离时正奖励
           + blocking_reward            # 1.5m 内、前方 0~8m 时正奖励
```

训练脚本 [train_adversarial_ppo.py](../training/train_adversarial_ppo.py) 会**再叠加** `adversarial_coef × (-avg(协作 agent reward))`，构造零和项。

### 5.1 标准 MAPPO 训练流（基线）

[train_no_rllib_mappo.py:107-354](../training/train_no_rllib_mappo.py#L107-L354)

```
for update in 1..updates:
    buffer = RolloutBuffer()
    obs = env.reset()
    for _ in args.rollout_steps:          # 默认 1024 步
        global_state = env.get_global_state()
        for each agent:
            action, logp = actor.sample_action(obs)
            value = critic(global_state)
            buffer.add(...)
        next_obs, rewards, dones = env.step(actions)
        if all(dones): obs = env.reset()  # 立即重置，继续填 rollout
    # PPO 更新（合并所有 agent 数据训 critic + 每个 agent 训自己的 actor）
    for _ in args.ppo_epochs (10):
        critic_step(...)                  # 合并 N×rollout_steps 训 critic
        for each agent:
            actor_step(...)               # 各自 rollout_steps 训 actor
```

**关键超参**（[build_parser](../training/train_no_rllib_mappo.py#L357-L390)）：
`lr=3e-4, gamma=0.99, gae_lambda=0.95, clip_eps=0.2, ent_coef=0.01, max_grad_norm=0.5, minibatch=256, hidden=128`

### 5.2 PPO 损失

```python
# critic
critic_loss = 0.5 · (return - V(s))²

# actor (Clipped Surrogate)
ratio = exp(logp_new - logp_old)
actor_loss = -min(ratio·adv, clip(ratio, 1-ε, 1+ε)·adv).mean()
           - ent_coef · entropy.mean()
```

GAE 公式（基线版 [compute_gae](../training/train_no_rllib_mappo.py#L70-L89)）：

```
δ_t = r_t + γ·V(s_{t+1})·mask - V(s_t)
A_t = δ_t + γ·λ·mask·A_{t+1}
```

`mask = 1 - done`。**基线问题**：rollout 内多 episode 拼接后调一次 GAE，episode 边界处 `mask` 不为 0 时优势跨 episode 泄漏 → v2 修复见下节。

## 6. Robust v2 的六大改动

完整 changelog 见 [robust_training_v2_changelog.md](robust_training_v2_changelog.md)，这里给出"做了什么 + 在哪里"的速查表。

文件：[train_no_rllib_mappo_robust_v2.py](../training/train_no_rllib_mappo_robust_v2.py)

### 改动 1：扩大 rollout，降 PPO epoch

| 参数 | v1 | v2 |
|---|---|---|
| `--rollout-episodes` | 4 | **16** |
| `--ppo-epochs` | 10 | **5** |
| `--min-transitions-per-update` | —  | **512**（不足则跳过更新）|

**位置**：[build_parser](../training/train_no_rllib_mappo_robust_v2.py#L864-L917)；skip 逻辑 [L621-L624](../training/train_no_rllib_mappo_robust_v2.py#L621-L624)。

**动机**：v1 默认 4 episodes × 平均几百步 = 千余 transition，跑 10 epoch 严重过度复用。增大 batch 同时减少 epoch 才稳。

### 改动 2：按 episode 独立 GAE + 截断 bootstrap

**问题**：原版把所有 episode 数据拼起来一次性 GAE，episode 边界处 `mask=1-done=1`（截断 episode 最后一帧 done=0），导致优势跨 episode 反向传播。

**修复**：
- `RolloutBuffer` 新增 [`episode_boundaries`](../training/train_no_rllib_mappo_robust_v2.py#L60) 和 [`mark_episode_end`](../training/train_no_rllib_mappo_robust_v2.py#L73-L82)
- 新函数 [`compute_gae_per_episode`](../training/train_no_rllib_mappo_robust_v2.py#L152-L190) 按边界切片独立计算
- 截断 episode 用 Critic 估计 `V(s_T)` 做 bootstrap（[L648-L654](../training/train_no_rllib_mappo_robust_v2.py#L648-L654)），自然终止 episode bootstrap=0
- 训练循环：每 episode 结束后 [`mark_episode_end`](../training/train_no_rllib_mappo_robust_v2.py#L598-L607) + 保存最后 `global_state`

### 改动 3：场景分层 + 加权采样

[`sample_scenarios_stratified`](../training/train_no_rllib_mappo_robust_v2.py#L197-L261)

| 模式 | 行为 |
|---|---|
| `random` | 等同 v1，纯 `np.random.choice` |
| `stratified` | 每个可用场景至少 1 个 episode |
| `weighted`（默认） | 至少 1 个 + 剩余按 `(1 - 成功率 + 0.1) × external_weight` 加权 |

CLI：`--scenario-sampling-mode {random,stratified,weighted}`

### 改动 4：课程软过渡

[`CurriculumLearning`](../training/train_no_rllib_mappo_robust_v2.py#L268-L398)

默认 3 个阶段：
- Stage 0：仅含 `basic` 的场景
- Stage 1：basic + left/right
- Stage 2：所有 8 个场景

**软过渡**：[`_compute_transition_alpha`](../training/train_no_rllib_mappo_robust_v2.py#L318-L349) 在阶段切换点 ±`transition_window/2`（默认 ±5）内线性插值 α，[`get_scenario_sampling_weights`](../training/train_no_rllib_mappo_robust_v2.py#L356-L382) 返回 `{scenario: weight}`，旧阶段场景以 `1-α` 权重保留。

**Bug 历史**（详见 changelog）：
- 第二轮：原本 `soft_weights` 未传入采样函数 → 现在通过 `external_weights` 参数显式传入
- 第三轮：`stage_start` 公式与 `_get_stage_idx` 不对齐导致 α 恒为 1 → 已对齐为 `warmup + stage_idx/n × (full - warmup)`

### 改动 5：逐 episode 优势标准化

[compute_gae_per_episode:180-184](../training/train_no_rllib_mappo_robust_v2.py#L180-L184)

```python
ep_std = adv.std()
if ep_std > 1e-6:                          # 短 episode（3~5 步碰撞）保护
    adv = (adv - adv.mean()) / (ep_std + 1e-8)
```

避免跨 episode 全局标准化压缩奖励量级差异（碰撞 -100 vs 完成 +200）。

### 改动 6：RolloutBuffer 增强

[`RolloutBuffer`](../training/train_no_rllib_mappo_robust_v2.py#L53-L101)

| 新字段/方法 | 作用 |
|---|---|
| `episode_boundaries[aid]` | `List[(start, end)]` 索引 |
| `episode_bootstrap_states[aid]` | `List[Optional[np.ndarray]]`，截断 episode 保存最后 `global_state` |
| `mark_episode_end(aid)` | episode 结束时调用 |
| `add_episode_bootstrap(aid, state)` | 自然终止传 `None`，截断传最后 `global_state` |
| `total_size()` | 跨 agent 总 transition 数（skip_update 判定用）|

### v2 vs v1 完整对比

| 维度 | v1 | v2 |
|------|----|----|
| rollout 数据量 | 4 ep | 16 ep（4×）|
| PPO epoch | 10 | 5 |
| GAE 边界 | 跨 episode 泄漏 | 独立 + bootstrap |
| 场景采样 | `random.choice` | 分层 + 加权（默认）|
| 课程切换 | 硬切换 | ±5 update 线性软过渡 |
| 优势标准化 | 全局 | 逐 episode + 短 ep 保护 |
| 跳过坏更新 | — | `n_transitions < 512` 跳 |

## 7. 对抗训练

### 7.1 训练流（[train_adversarial_ppo.py](../training/train_adversarial_ppo.py)）

- Agent 0、1：从 `--pretrained-ckpt` 加载预训练 MAPPO 策略，**冻结**（不算梯度）
- Agent 2：使用 PPO + `PerAgentCritic`（[actor_critic.py:76](../models/actor_critic.py#L76)）训练
- 环境构造时 `adversarial_agent_ids=[2]`，env 内部对 agent 2 调用 [`_compute_adversarial_reward`](../environment/carla_multi_agent_env.py#L1491)
- 训练侧再叠加零和项：`final_reward = env_adv_reward + adv_coef × (-avg(agent0,agent1).reward)`
- 支持 `--curriculum-learning`：warmup 阶段仅用基础驾驶奖励，逐步 ramp `adv_coef`

### 7.2 可视化

[`AdversarialVisualizer`](../visualization/visualize_adversarial_training.py)：pygame，左侧三摄像头视图 + 右侧每 agent 即时 reward 与累积 reward 条形图。

## 9. TensorBoard 指标全表

完整说明见 [tensorboard_metrics_guide.md](tensorboard_metrics_guide.md)。这里只列结构。

```
episode/
  avg_return / std_return / avg_length
  success_rate_window         ← 主要看这个
  success_rate_cumulative     ← 长期参考
  return_agent_0 / return_agent_1
  n_transitions

reward/                       ← 各分量每步均值
  progress / speed / centering / yaw
  collision / lane_invasion / step / success
  jerk / steer_rate / safety_lidar / ttc / time_bonus     ← v2 独有

ppo/
  critic_loss / critic_grad_norm / explained_variance     ← 看 EV 趋近 1
  actor_loss_agent{0,1}
  entropy_agent{0,1}          ← 别趋零（=探索崩溃）
  approx_kl_agent{0,1}        ← 0.001~0.01 健康
  clip_frac_agent{0,1}        ← 0.05~0.2 健康
  grad_norm_actor_agent{0,1}

scenarios/{name}/
  success_rate_window         ← 滑窗 20
  sample_count
```

调参快速指南：
- `entropy` 趋零 → 增大 `--ent-coef`（0.01 → 0.02）
- `approx_kl > 0.05` 或 `clip_frac > 0.5` → 降 `--lr-actor` 或缩 `--clip-eps`
- `explained_variance < 0` → 检查 `critic_loss` 是否在降，可调 `--lr-critic`
- `actor_loss` 震荡发散 → 降 `--lr-actor`，增大 `--minibatch-size`

## 10. 运行手册

### 10.1 准备

```bash
# 1. 启动 CARLA Server（项目根目录）
./CarlaUE4.exe -quality-level=Low

source venv/Scripts/activate

```

### 10.2 常用训练命令

```bash
# 标准 MAPPO 基线（v2 奖励）
python -m training.train_no_rllib_mappo --reward-version v2 --render

# 推荐：robust v2，weighted 采样 + 软过渡
python -m training.train_no_rllib_mappo_robust_v2 --render

# 复现 v1 行为以做对比
python -m training.train_no_rllib_mappo_robust_v2 \
    --rollout-episodes 4 --ppo-epochs 10 \
    --scenario-sampling-mode random \
    --curriculum-transition-window 0

python -m training.train_adversarial_ppo \
    --pretrained-ckpt ./logs/minimal_mappo_ckpts/mappo_ctde_mappo_update_100.pt \
    --curriculum-learning
```

```bash
# 标准评估
python -m evaluation.evaluate_no_rllib_mappo --checkpoint <path.pt>

# 鲁棒性评估（多场景）

    --num-episodes-per-scenario 5 --output-file results.json

python -m evaluation.compare_reward_versions \
    --checkpoint-a ./logs/ab_v1_ckpts/ckpt_500.pt --label-a "v1" \
    --checkpoint-b ./logs/ab_v2_ckpts/ckpt_500.pt --label-b "v2" \
    --episodes 50 --use-random-scenarios
```

```bash
tensorboard --logdir PythonAPI/examples/mappo_training/logs/
```
