# 相关论文检索与实施细节依据

日期：2026-10-08。目的：为Mut-MAPPO两红两蓝任务、教师选择、通信与风格池的待定细节提供依据。本轮仅检索原论文、官方会议页及作者全文，核对相关方法/实验段落；这是定向检索，不是穷尽式查新。未改训练源码、未启动CARLA。

用户已确认第一点为蓝方协同对抗。主动撞击是否允许等研究边界仍待确认；以下“项目建议”是从文献得到的设计推论，不作为用户已批准的配置，也不套用其他方法的理论保证或数值。

## 1. 最贴近蓝方任务的依据

| 原始论文 | 核对位置与经验 | 对项目的建议与边界 |
|---|---|---|
| [VDARS：Multi-Agent Vulnerability Discovery for Autonomous Driving Policy by Finding AV-Responsible Scenarios，CASE 2024](https://nicsefc.ee.tsinghua.edu.cn/nics_file/pdf/26112ddf-6f61-441f-a880-006e87b93232.pdf) | III-B/C/E：MAPPO多攻击车；目标碰撞奖励结合攻击方激进行为成本；指出攻击者必须存活/到终点会排除一些有价值案例 | 是最接近的任务参照。接触、主动撞击和被测策略弱点分开记录；HAR只是规则代理，不是完整法律判责。其换道惩罚不能直接用于合法并线任务 |
| [STRIVE：Generating Useful Accident-Prone Driving Scenarios via a Learned Traffic Prior，CVPR 2022](https://nv-tlabs.github.io/STRIVE/docs/strive.pdf) | 正文3.2/4.1与附录C.4/C.8：合理性约束、避险解搜索、多车间接协同；避险解可能使用未来信息 | 借鉴动力学/道路合理性与典型案例可避性审查，不复制交通先验模型。找到离线避险轨迹不等于证明在线红策略能避免 |
| [CAT：Closed-loop Adversarial Training for Safe End-to-End Driving，CoRL 2023](https://proceedings.mlr.press/v229/zhang23g/zhang23g.pdf) | 3/4.3：利用当前目标策略响应生成困难轨迹；留出正常/对抗场景同时报告碰撞和路线完成 | 冻结当前红策略作蓝训练目标；普通交通与对抗交通配对，避免把增加交通本身当攻击收益。其闭环红训练收益不能套给本阶段冻结红方 |
| [Learning to Collide，IROS 2020](https://arxiv.org/pdf/2003.01197) | III-B：场景参数边界、风险/碰撞目标与不合理初始占路惩罚 | 借鉴出生位与初始合理性检查。它主要生成场景参数，不是可直接复用的两蓝连续控制训练器 |

**应补进任务合同的建议：**

1. 蓝方有共同速度、动力学、道路边界与基本行驶成本。防永久停车堵路可用软进度/停滞成本；不把“蓝方到终点”当攻击成功的必要条件。是否保留蓝路线任务及完成后如何处理仍需冻结。
2. 不把“蓝方任何接触”自动解释成主动撞击。保存对象、位置、相对速度、动作时间窗和规则证据；先分明显主动撞击、被测红方避险不足候选及未知，不通过sensor触发先后判责任。
3. 若采用绝对无蓝接触要求，将任务明确限定为安全困难交互；该定义会排除部分事故漏洞案例。原计划中的无接触q可保留为过程指标，不能覆盖所有红方失败成果。
4. q_response记录显著响应并标注合理让行；q_failure_evidence记录失败与交互证据。最终同时报告红方完成、效率、近失/失败及蓝方合规，不能用一个碰撞率概括全部收益。
5. 保留C0两红无蓝、C1相同初态的普通蓝交通、C2学习蓝策略；固定红权重、规则及案例键。AttackGain=Success(C1)-Success(C2)仅作配对效果量，不是单个事故责任证明。蓝方失效造成的全局截断另标，不自动写成红方超时。

这些合同设计由上述任务方法启发，具体分类和C0/C1/C2差值是本项目设计，并非原论文统一规定。

## 2. 互学习与教师选择的最直接参照

| 原始论文 | 核对位置与经验 | 项目含义 |
|---|---|---|
| [Dual Policy Distillation，IJCAI 2020](https://www.ijcai.org/proceedings/2020/0435.pdf) | 3.1/3.2、式9/11/12、4.2：价值优势选择，实际使用软权重应对硬判别误差；PPO/DDPG连续任务；按双学习器总步数比较 | 是必须讨论的最近邻方法。不能把双策略、连续动作和优者指导弱者当原创；q/b场景门控不继承其逐状态理论。总仿真预算对齐有直接先例 |
| [Policy Distillation and Value Matching in Multiagent Reinforcement Learning，2019作者全文](https://arxiv.org/pdf/1903.06592) | III-A/B：同输入actor蒸馏；强蒸馏后critic不匹配可能导致遗忘；value matching依赖同质角色置换 | 保留同角色/同输入与小幅辅助更新，critic继续学习本方真实回报。固定角色、路线和奖励不对称时不直接加入value matching |
| [KnowSR：Knowledge Sharing among Homogeneous Agents in MARL，2021作者预印本](https://arxiv.org/pdf/2105.11611) | 3.3与算法1：同观测建议、暖启动与周期知识分享 | 暖启动、周期快照和分享频率均有经验依据；不作为独立创新，也不照搬其动作MSE取代完整随机策略分布 |
| [MAPPO：The Surprising Effectiveness of PPO in Cooperative Multi-Agent Games，NeurIPS 2022](https://papers.nips.cc/paper_files/paper/2022/file/9c1535a02f0ce079433344e14d910597-Paper-Datasets_and_Benchmarks.pdf) | 3/5：on-policy、价值归一化、过度样本复用和较大更新会影响协作学习 | 保留独立PPO采样，监控真实策略更新幅度；辅助KL不得绕开更新约束。其SMAC/MPE超参不是CARLA默认值的直接依据 |

DPD实际选择权重为`exp(alpha * (V_peer(s)-V_self(s)))`，其理论涉及同一任务与状态访问分布假设，原实验采用动作MSE。项目采用Gaussian KL和场景族q/b行为评价，是需要说明的适配差异。若做DPD式参考对照，需要共同奖励/折扣/输入，ValueNorm反归一化后比较；各队动态安全系数若不同，价值差含奖励尺度差，不能直接充当动作质量。

**对现有门控规格的处理：**

- 当前每类8例、领先2例、安全失败不超过1例没有找到直接可套用的文献依据，保留为一次先导候选，不称统计保证。
- 冻结教师、配对验证案例、记录q/b/样本数及门控重复稳定性；频繁翻转时再考虑平滑/软权重，不同时堆新网络。
- 教师场景平均优势不保证学生任意状态上动作可靠；先限制同场景族/同角色，不宣称逐动作安全迁移。
- 门控使KL平均强度下降，先登记等覆盖随机门控或等平均强度普通互学习的小预算定位分支。该对照是本项目的归因设计，不是上述论文给出的固定实验。
- 如果要主张算法创新，补与DPD式选择的差异和必要比较；如仅完成B0/B1/B2，先报告领域任务中的组件效果，不能预先宣称更先进。

## 3. 通信与丢包实验

[TarMAC，ICML 2019，4节式2/3](https://proceedings.mlr.press/v97/das19a/das19a.pdf)用本地信息产生消息与注意力，原版聚合包括自身消息。因此，只有排除自身且仅剩一个队友候选时softmax恒为1；两辆车本身不必然使TarMAC退化。

[Message-Dropout，AAAI 2019，3节及4.4/4.5](https://ojs.aaai.org/index.php/AAAI/article/download/4564/4442)按发送者整块丢弃消息，保留本地观测，并测部分/全部连接失效。完全失联时，有通信方法未必优于独立策略。

**项目适配建议：**首版单轮8维消息、拼接或标量门控及可用mask即可；attention若采用self/null候选，说明它检验自我/队友权衡，而不是多目标寻址。通信时序另需固定，同步单轮与TarMAC延时/多轮并不等价。先保持MLP/PPO主体不变，避免把GRU、共享参数等额外变化混入通信收益。

PPO重算概率时复用采样时消息丢包mask，是本项目正确性要求；原Message-Dropout不是MAPPO实现。最终测试正常、部分丢包和全失联，固定模型/案例；置零测试不代替从头训练的无通信组。训练丢包作为独立开关，不能悄悄只给主方法数据增强。

## 4. 驾驶风格与种群

[Interaction-aware Decision-making for Automated Vehicles using Social Value Orientation，2022作者全文，V-B/C和VI-D/E](https://arxiv.org/pdf/2207.05853)通过自身/他人收益权衡培养不同表现，并在相同初始条件比较轨迹、任务时间、距离和加速度。文中曾观察到改变SVO仍全学成激进策略，后来调整交互对象训练安排才改善。这说明风格系数并不保证实际风格形成；原任务是二维车—行人，不能视为四车CARLA已验证。

项目采用共同安全标准，分别改变效率、舒适性和礼让偏好；用相同跟驰/并线/让行探针验证时距、制动、间隙和效率。速度偏好不是完整社会风格，出生速度差更不是策略风格。

[Policy Space Diversity for Non-Transitive Games，NeurIPS 2023，2.2/3/4节](https://proceedings.neurips.cc/paper_files/paper/2023/file/d61819e9b4a607b8448de762235148c4-Paper-Conference.pdf)讨论PSRO，给出payoff多样性增加不必改善博弈解的反例。

项目分别验证行为风格覆盖和对未知对手能力，不认为池越多样就必然更强。风格培养奖励可以不同，payoff使用共同外部指标；若不同安全成本构成一般和博弈，保留双边收益，不自动称严格零和。风格最低采样概率属于工程覆盖方案，不宣称精确均衡保证。保持固定单策略、等规模同风格池、多风格均匀池、多风格PSRO比较，未知风格参数、新seed及混合团队单列。

## 5. 评估的最低合理要求

[Deep Reinforcement Learning at the Edge of the Statistical Precipice，NeurIPS 2021，3/4节及表1](https://proceedings.neurips.cc/paper_files/paper/2021/file/f514cec81cb148559cf475e7426eed5e-Paper.pdf)强调少量训练重复下不能忽略不确定性，并建议区间及分布报告。

本项目维持主对照3个外层seed的月底起点，同时展示每seed/场景结果和不确定性；不能把1600个episode当1600次独立算法重复。三seed是资源选择，不是该论文规定的足够样本量。C1/C2配对按案例键统计，失败/超时与到达时间一起报，避免只展示成功子集速度。

## 6. 现有计划应据此补充什么

| 细节 | 文献支持的方向 | 本项目仍需定标/确认 |
|---|---|---|
| 蓝方行为 | 物理/道路合理性、明显主动冲撞与有价值失败区分 | 是否绝对无接触；合法并线/短时阻挡边界；蓝任务与终止 |
| 有效交互 | 响应、失败、合理性分层 | 减速/偏转持续阈值，正常让行标签，证据分类 |
| 教师选择 | 选择性分享有先例；硬判别有估计误差 | 8/2门槛、刷新频率、稳定性和KL权重 |
| 公平预算 | 双学习器合计训练步数 | 最终tick上限；另报验证、更新时间及墙钟 |
| 通信 | 本地消息、丢包、保留自车信息 | 消息时序/维度/mask协议；attention实际候选 |
| 风格池 | 不同奖励偏好要有行为证据 | 风格培养配置、共同探针与最低能力要求 |
| 种群收益 | 共同payoff、覆盖与能力分别测 | 元策略/一般和处理、首轮PSRO预算 |

建议当前继续采用“普通互学习基线＋一个选择机制”，把q_response与失败证据拆开，补共同任务/事件合同及最近邻比较。首版不复制STRIVE生成模型、不加完整责任审判器、不引入所有论文模块。现有候选数值仍由一次先导确定；论文经验用于确定结构和证据要求。
