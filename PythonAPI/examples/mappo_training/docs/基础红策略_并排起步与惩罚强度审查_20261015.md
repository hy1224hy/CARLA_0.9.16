## 1. 实际场景确实全部近似并排，但不全是静止起步

当前u456及V5使用的是 `data/training_scenarios_town05_r8a_v1` 的12例，不是仓库其他目录中的16/32例。逐文件计算两车相对行驶方向的纵横投影，横向中心间距约3.5m，最大纵向错位约0.01m。

| 类别 | 数量 | 两车初速度 | 路线 |
|---|---:|---|---|
| 南北短滚动 | 2 | 均2m/s | 约15m |
| 南北短静止 | 2 | 均0 | 约15m |
| 四方向长畅通 | 4 | 2/4m/s，快慢角色随方向配置 | 约42–45m |
| 四方向长静止 | 4 | 均0 | 约39.5–45m |

合计6例静止、6例滚动。四个长畅通案例有初速度差，但初始纵向位置仍并排；不能将其称为已覆盖稳态跟驰/前后起步。所有案例 `goal_mode=preserve_start_lane`，环境为每车生成各自车道的目标框（半长3m、半宽1.6m），不是共同争抢一个窄终点。

这套池适合作为直行/起步课程，但初始纵向间距、正常交互与单车能力覆盖偏窄。并排常态可能使策略对邻车关系过拟合；“因此学会等待队友到达”仍需要配对干预证明。

## 2. 当前不能统称为前车到达后后车才起步

复用2026-10-13的V5 u461冻结评估，起步时间定义为首次达到0.5m/s，不代表持续运动资格：

| 案例 | agent0首次运动/到达（秒） | agent1首次运动/到达（秒） |
|---|---|---|
| SC04南短静止 | 0.5 / 2.4 | 2.1 / 4.8 |
| SC10南长静止 | 0.5 / 5.7 | 2.6 / 10.5 |
| SC11东长静止 | 0.5 / 4.6 | 3.0 / 10.7 |

上述后车已经在前车到达前运动；全部11个有agent0到达的V5案例也满足这个首次运动时序。当前主要可确认的是启动迟滞、行驶速度与到达时间不对称，不能由到达顺序推断完整停车等待或到达事件触发。历史u208 SC04确有前到后起步轨迹，不能用来替代当前V5证据。

独立Actor允许角色分化；两车到达即销毁，使错开通行可能降低相互接触风险；gamma=0.999对几秒等待折扣有限。这些是机制候选，尚无因果消融。当前前车受阻效率豁免要求车体坐标横距<2m且前方0–12m；正常直行并排约3.5m，不能直接断言旁车自动触发该豁免。

如要定位原因，可候选在同一冻结策略、同一后车初态下，对比邻车并排、纵向错开、移远，并镜像左右/角色；记录持续运动、同时运动比例、邻车消失/驶出感知范围和后车响应。该干预是机制诊断，不混入既有正式成绩。尚未实施。

## 4. 惩罚强度与调整顺序

V5超速成本为 `-dt*(0.5e+0.5e²)`，`e=max(0,(v_kmh-15)/15)`；15km/h为任务偏好上界，不是道路法定限速结论。以下为固定状态下未折扣的每秒成本，不是独立驾驶效果：

| 状态 | 每秒成本 |
|---|---:|
| 20km/h | -0.2222 |
| 30km/h | -1.0000 |
| 40km/h | -2.2222 |
| 偏离1.0m | -0.1244 |
| 偏离1.25m | -0.2000 |
| 偏离2.5m | -0.8096 |

车道项是 `-0.1*dt*(u+u²)`，`u=max(0,(d-0.35)/0.9)`。合法变道事件为0；非法跨线事件为-2；持续明确道路违规终止为-50。合法转移有宽限且可更新参考车道，不能把所有变道统一加罚。当前直路任务没有必须换道的瓶颈，偏离/非法横切是重点。

已有V5轨迹中，agent0的SC06超速累计约-7.72、进度18.51、到达+20；SC10超速约-7.58。超速成本已经实际生效，并非只写入配置。SC01碰撞前agent0累计参考车道偏离成本约-0.077、进度10.45，说明短时早期侧向偏离的密集反馈较小；这支持优先审查早期侧向安全，但不能只凭回报分量大小确定最优系数，也不能把代数加倍计分当作学得更安全。

建议保持两条区别：

1. 先固定V5给予适应窗口。它只有5个新updates/80个回合，继承了u456低学习率、旧Critic/ValueNorm；不能把未适应与系数不足混为一谈。已有候选25/50/100新updates分段方案仍未执行。
2. 若充分适应后超速仍稳定，则单独比较超速成本倍率，保持源、场景、预算与其他项一致；若横漂/违规仍主导，则单独比较早期偏离/安全反馈。不要同时加大两项再宣称原因明确。终局安全成本已有-50，不优先盲目继续抬高。
3. 不为追求同步加入双车速度差或到达间隔罚款。基础目标是两车各自安全、合理高效完成，速度不同本身不等于失败。
4. 场景扩展另立版本，保留当前12例用于可比性；候选增补纵向错位、正常跟驰/减速和左右角色变化，并留出组合。不要直接改冻结目录后称严格恢复。
