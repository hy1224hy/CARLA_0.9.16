# Mut-MAPPO 四车任务／奖励／指标合同（集中审核页）

日期：2026-10-09，Asia/Shanghai。版本：candidate v0.1。**科研配置状态：候选；公共程序已按用户开发授权在当前分支实现，尚未运行CARLA。** 本页不把开发授权或交接文本视为未确认科研边界的批准；实现证据见[开发进度](./MutMAPPO开发进度_20261009.md)，工程细节见[公共20/2实现清单](./MutMAPPO公共20_2实现清单_20261009.md)。

| 合同项 | 推荐默认方案 |
|---|---|
| 角色与接口 | Town05，0.1 s；红0/1冻结正常驾驶，蓝2/3协同对抗。无通信版 Actor 明确20维观测／2维策略动作；蓝2←基础角色0，蓝3←角色1。A/B是串行使用这四辆车的两套蓝团队，分别有Actor、Critic、优化器与随机流。 |
| 场景与目标 | 首个工程闭环用“追近／短时阻挡、合法切入”2族×北南2方向。红保持各自目标车道；蓝保留同向路线进度，允许目标走廊内合法换道，蓝到达不是攻击成功硬条件。复用Road44/3道路模板按弧长生成四车初态；无重叠、可达性与换道标线须实际核验。正式方向、扰动、案例清单在先导后冻结，调试4格不冒称覆盖原16模板。 |
| 对抗边界 | 允许同向合法跟驰、并线和短时阻挡；主动冲撞、逆行、实线跨越、路肩捷径不属于允许行为。接触保留对象／帧／冲量证据，任蓝接触计蓝安全失败，不发碰撞攻击奖金；规则分类不宣称法律责任。 |
| 防刷分与驻停 | 出生3 s内全部攻击加分关闭，安全成本照常。候选上限：宽限后，非终点减速区、前方无可见阻挡且沿路线速度<0.2 m/s连续3 s，记蓝任务违约并移除；豁免各组相同。计时需记录，20维Actor下终局存在部分可观测性。任务违约不伪称交通违法。场景时限初值50 s；数值仅允许一次先导定标。 |
| 生命周期 | 到达车辆移除。蓝碰撞／越界／道路或任务违约只终止该蓝；两蓝退场后红仍运行。红真实碰撞／越界／道路违规可结束全局，另一未完成红记外部截断；红都到达或真实任务期限结束才记团队成功／任务超时。红结束时尚存蓝的任务自然结束，不把环境故障／预算中断算红失败。 |
| 共同奖励 | 两有效蓝共享一次团队攻击事件项，个体路线／平滑／畅通低速成本与非负安全成本分开：`r_b = I_team + T_team + 0.3*R_drive,b - lambda_k*C_b`。事件按红车去重；候选减速事件+5、每红最多3次，关联真实任务超时+15一次；碰撞奖金0。响应门控威胁项全团队累计≤20；出生期／无效行为不得加分。沿路线即时速度缺口代替隐藏累计pace欠账，超速成本持续增长；不再额外减红方私有return。初值来自旧奖励结构，具体量纲／成本系数统一定标后冻结，各B组完全相同。 |
| 响应q与行为b | 候选响应：保护期后，蓝在红前方3–15 m、横向≤2.5 m，红2 s内降速≥2 m/s且持续≥0.5 s；排除起步／终点减速。`q=蓝全回合合格且有证据事件数/N`，`b=任蓝碰撞／越界／道路或任务违约回合数/N`；N为全部有效回合，不能只除合格子集。正常礼让仅记响应，转向突增只诊断；q/b是代理。 |
| 外部评估与选模 | C0无蓝；C1同蓝初态冻结普通蓝；C2学习蓝，固定红hash、车型、目标、时限与案例键。报`AttackGain=SR(C1)-SR(C2)`，另拆安全合格配对贡献／unsafe贡献及红完成度／失败／效率；到达延迟注明成功条件。环境故障等按配对键共同重跑或排除并报invalid。四类清单分离；selection安全过滤后按安全合格AttackGain、q、违约数选一团队，保留A/B。test不选模。 |
| 方法、预算与运行 | B0=off双独立团队；B1=plain；B2=selective。学生同角色同输入对冻结教师做`KL(student||teacher)`，各自轨迹仅用于本方PPO。候选beta=0.01，暖启5轮、每10轮刷新；每族各8例，教师b≤1/8且≤学生、q领先≥2/8才启用。三组同验证安排；A+B训练world ticks等预算（含训练reset），分报决策／reset／验证／总ticks。共享2000、唯一tick控制者；长跑跟踪镜头＋20分钟纯文件巡检＋完整A/B原子断点。 |

**本次集中审核三个科研选择：**①采用上述“允许合法短时交互、接触计成本且不给碰撞奖金”的边界；②保留蓝自身路线软目标及候选3秒畅通驻停任务上限；③q只作响应／教师代理，主结论依靠配对性能下降和蓝安全，随后按B0→B1/B2→三seed正式对照与通信→风格池／PSRO顺序推进。技术常数由一次先导定标，不能为了触发门控反复修改。通信明确保留为点一交付，不用消息置零替代无通信训练组。
