# Town05 并排/并道训练试验方案（已被正式 v1 取代）

> 本文仅保留早期 pilot 过程。正式实验请使用 [Town05 正式实验迁移与 16 场景设计](./Town05_正式实验迁移与16场景设计.md)；不得把 pilot 场景或 smoke 合同混入正式训练。

## 结论

Town02 是只读历史基线，不再续训。Town05 正式 v1 使用独立的场景目录、路线清单、合同和输出目录。2026-08-12 的早期真实 CARLA 测试表明：本机可以运行双智能体 Town05 小规模训练，8 个 pilot 场景均能稳定初始化，并且完成了 1 次真实 PPO 更新。

这只是“可运行性门槛”的历史证据，不等价于策略已经收敛，也不等价于长时间训练的热稳定性已经验证。后续 gamma 审计还发现该 PPO smoke 的训练环境实际使用默认 0.99，而合同意图/PPO 使用 0.997；因此它不能作为正式奖励协议证据，必须以正式 v1 修复后的新 smoke 为准。

## 路线设计

所有坐标来自 `Town05.xodr` 的车道中心线。主试验选 Road 44：连续直道约 61 m、同向双车道中心距 3.5 m、中间虚线允许换道，且起终点避开路口人行横道。

| 路线 | 用途 | 车道 | 起点（两车道中心） | 航向 | 终点 |
|---|---|---|---|---|---|
| T05_R44_N | 第一阶段训练/冒烟 | 2, 1 | (-195.09,-64.58), (-191.59,-64.58) | 90° | 双车道中心 (-193.33,-14.58)；并道目标在 lane 1 (-191.59,-14.58) |
| T05_R44_S | 第一阶段训练/冒烟 | -2, -1 | (-184.58,-19.59), (-188.08,-19.58) | -90° | 双车道中心 (-186.33,-69.58)；并道目标在 lane -1 (-188.08,-69.58) |
| T05_R3_EW | 第二阶段东西向泛化 | ±1, ±2 | 见路线清单 | 0°/180° | 约 45 m 双车道直行 |
| T05_R43_NS | 第二阶段南北向泛化 | ±1, ±2 | 见路线清单 | 90°/-90° | 约 48 m 双车道直行 |
| T05_R6_EW | 独立留出评估 | ±1, ±2 | 见路线清单 | 0°/180° | 约 44 m 双车道直行 |

完整精确坐标在 `data/town05_parallel_routes_v1.json`。第一阶段只使用已在线验证的 Road 44；Road 3、43、6 在加入训练前仍需按同样流程做在线生成校验，避免一次引入过多变量。

## 8 个第一阶段场景针对的问题

| 难度 | 场景 | 主要检验问题 |
|---|---|---|
| D1 | 南/北向静止并排，左右角色镜像 | 基础策略是否在真正并排初始条件下稳定起步，是否存在固定车道/固定 agent 偏置 |
| D2 | 南/北向 3 m/s 同速并排，左右角色镜像 | 滚动初始化后能否维持并行、感知侧向车辆并避免无意义抢道 |
| D3 | 南/北向 3 m/s 跨车道错位，前后角色镜像 | 车间交互、盲区/侧后方约束、时序决策，而不是只学静态横向关系 |
| D4 | 南/北向错位且一个 agent 必须汇入单车道目标 | 真正的并道决策、让行/抢行博弈与碰撞规避；窄目标确保不并道就不能成功 |

每个难度 2 个场景，方向为北向 4/南向 4；左右、前后和并道主体均做 agent0/agent1 镜像，防止策略利用身份捷径。

## 实测结果

测试条件：CARLA 0.9.16，端口 2000，Town05，Low quality，离屏运行，训练策略在 CPU，2 个车辆，不启用旧可视化。

| 门槛 | 结果 |
|---|---|
| OpenDRIVE 几何/方向/可换道/场景平衡 | 8/8 通过 |
| 在线生成 | 8/8 通过；最大位置误差约 0.01 m |
| 滚动初速 | 实测 2.96 m/s，目标 3.00 m/s |
| 在线生成总耗时 | 29.01 s（包含地图切换/首次缓存） |
| 训练 | 2 episode，428 transitions，完成 update 1 |
| 环境吞吐 | 38.91 transitions/s |
| PPO 耗时 | 0.358 s |
| 完整训练命令耗时 | 34.74 s |
| 参数更新 | actor0 0.004442、actor1 0.004465、critic 0.009143（relative update norm） |
| 数值健康 | checkpoint 86 个 tensor、指标文件均无 NaN/Inf |
| 清理 | 训练后车辆 0、传感器 0，无 CARLA actor 泄漏 |

随机初始化策略的两个 episode 分别以 1 次碰撞和 1 次超时结束。这对未训练策略是合理行为；本次门槛验证的是仿真、采样、反向传播、checkpoint 和清理链路能否完整运行，不以成功率作为通过条件。

资源快照（训练结束后采样）：CARLA working set 约 2.36 GB、private memory 约 5.69 GB；系统可用内存约 4.51 GB；RTX 4060 Laptop 8.19 GB 中全系统占用约 3.51 GB。该快照不是峰值监控，但结合真实更新无 OOM、无超时，可判定当前小规模 pilot 可运行。正式长训前建议先跑 10 updates 并监控温度、内存增长和 transitions/s，再决定是否扩大 rollout。

日志和 checkpoint 位于 `diagnostics/town05_parallel_smoke/T05_parallel_smoke_s42_20260812_1045/`。

## 即插即用命令

保持 CARLA 在 2000 端口运行，然后在 `PythonAPI/examples/mappo_training` 下执行：

```powershell
..\..\..\venv\Scripts\python.exe -B -m utils.run_town05_pilot
```

该命令依次做离线几何校验、8 场景在线生成校验和 1-update 训练冒烟，不调用旧可视化。只检查坐标而不连接 CARLA：

```powershell
..\..\..\venv\Scripts\python.exe -B -m utils.run_town05_pilot --offline-only
```

下一阶段建议使用相同入口先跑 `--updates 10 --rollout-episodes 4 --max-steps 300`。只有在无内存爬升且吞吐稳定后，再把 Town05 升级为正式实验契约；Town02 始终保留作对照组。
