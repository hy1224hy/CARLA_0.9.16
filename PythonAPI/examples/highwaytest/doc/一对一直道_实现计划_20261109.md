# 一对一直道实施计划

目标：实现已确认的一网络对抗车、一IDM/MOBIL目标车、22维观测、三级奖励及双副本PPO互学习，提供校准、基础驾驶初始化、训练、续训、评价、矩阵与汇总入口。

架构：新增`PythonAPI/examples/highwaytest/straight/`，与旧Team/runner协议隔离；环境、奖励状态机、单actor网络、训练器、CLI分模块。配置、源身份、RNG、预算及独立选模随checkpoint记录。默认不启动正式长训。

- [ ] 环境/奖励：先测试碰撞符号、事件优先级、物理子步时钟、22维观测及参考隔离，再实现config/rewards/environment。新环境API为reset(seed,options)、step(u)、render/close；info包含reward_components和各任务指标。
- [ ] 网络/训练：先验证同输入冻结教师、PPO概率、单副本动作和GAE，再实现model/learning/runner。A+B合计预算、独立随机流、β warmup/ramp、普通双副本公平对照；只在边界恢复。
- [ ] 脚本：提供bootstrap、train、evaluate、plan、batch、report、calibrate，参数验证且防止覆盖既有结果。基础BC后按等级分别初始化，目标和正常参考均允许MOBIL换道。
- [ ] 整合：实跑短程三级环境、BC、训练、续训、评价和TensorBoard，运行新旧回归；修复实际发现的问题，不将短测宣称为策略收敛。
- [ ] 交付：中文运行说明、矩阵配置、审查记录和源入口链接。

验收命令从`PythonAPI/examples`执行，使用仓库venv：`python -m unittest discover -s highwaytest/tests -p "test_straight*.py" -v`与旧回归；`python -m highwaytest.straight --help`；独立临时输出目录完成短闭环。实现不自动提交或启动长训练。
