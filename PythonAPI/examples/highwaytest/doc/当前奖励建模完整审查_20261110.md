# 当前奖励建模完整审查

审查日期：2026-11-10。对象为当前`straight/rewards.py`、`environment.py`、`runner.py`、`learning.py`和a2c配置。只做静态、数学及已有日志分析；未修改训练代码或重启训练。代码仍可能在其他会话中更新，本文描述本次读取版本。

## 1. 总体判断

三级行为目标、正常交通参考、等级相关碰撞符号、固定时窗、一次事件检测及物理子步统计，构成了可解释的实验框架。但“合理描述目标”与“为普通驾驶网络提供可学习的优化路径”尚未同时实现。

主要问题不是某个权重小数值选错，而是目标、稠密信号、事件边界、历史状态和选模存在错位。L2最突出：完成第一次几何切入之前几乎没有横向任务引导；完成之后又存在与正式成功不一致的正收益区域。当前代码也不是多次有效别车目标。

合理性可分为：概念框架可保留；事件语义及训练/评价一致性需要优先修订；具体权重没有充分实验证明最优。互学习不会自动纠正奖励指向错误。

## 2. 实际公式与符号

物理步dt=1/15秒，策略5Hz，一个策略步通常累加3个物理步。固定T=20秒，密集项乘dt/T。一次性事件和终止奖金不乘dt/T。

```text
ell=(v_reference-v_target)/max(v_reference,5)
d=clip(ell,-1,1)
m=1[前方关联 && 0.10<=ell<=0.35 && a_target>=-3]
h=1[曾完成几何切入 && 当前前方关联]*clip(1-THW/1.5,0,1)
THW=保险杠纵向间距/max(v_target,2)
c=clip((Δu_acc²+Δu_steer²)/8,0,1)
```

默认effect_weight、risk_weight、event_weight均为1：

```text
L1: (dt/T)*(2*d+m-.05*c) +4*终止成功 -20*目标碰撞 -10*越级 -20*无效
L2: (dt/T)*(d+2*h-.05*c) +2*首次有效别车 +5*终止成功 -20*目标碰撞 -20*无效
L3: (dt/T)*(.2*d+.5*h-.05*c) +20*有效目标碰撞 -20*无效
```

另加`geometry_weight*(gamma*Phi_next-Phi_now)`，真正终止的Phi_next置0。默认geometry_weight=0，最新a2c实际配置为0.5；旧批结果与最新引导版本不能混为同一奖励配置。

同一帧优先判无效，再判目标碰撞，再判L1越级，最后才发普通事件或时窗结束奖金。目标碰撞在L1/L2为负、L3为正；初始化重叠不算碰撞成功。

## 3. 值得保留的设计

### 3.1 比普通交通多造成多少影响

C1/C2相同初始状态、相同目标规则，C1将对抗车换成正常IDM/MOBIL。它比直接负目标车回报更容易解释，也比只看目标速度低更能排除自然交通影响。

参考不进入actor，避免网络读取另一条未来轨迹。ell保留负值，也优于只奖励正向损失。需要将其称为“相对所选正常控制器的额外影响”，不是已证明唯一因果责任。

### 3.2 时间和量纲

逐步项归一化使其总量可控，不至于100步不断堆积后淹没事件。事件只支付一次，避免每个物理帧重复奖励同一次碰撞或别车。

### 3.3 三个等级采用不同终点

轻度阻碍、非碰撞切入、目标碰撞是可检验的不同目标。碰撞正负随等级改变，解决了统一安全奖励与L3目标的直接矛盾。

### 3.4 没把几何换道直接当成攻击

L2还要求位置、对齐、间距与目标反应；目标主动换道不自动归功于对抗车。指定车辆实际接触与任意crashed标记也有所区分。

## 4. L1：有限阻碍的目标与奖励存在冲突

当前成功是累计m对应时间>=1.5秒，并在整回合没有越级或无效事件。不是连续阻碍1.5秒，也不是整回合持续轻度阻碍。

**已确认的问题一：主要效率项仍单调奖励更大损失。**ell=.2时效率项为.4，ell=.5时为1.0。m在超出35%时消失，但基础效率项没有同步变坏。策略在“制造更大损失”和“避免持续越界”之间博弈。

越级通常需要持续计时，因此短暂超界、恢复、再超界的轨迹可能获得密集收益而不触发连续时长门槛。是否实际形成这种投机需要轨迹证据，但目标函数确实允许这条路径。

更一致的方向是在轻度区间达到最大收益，超过区间后收益下降或出现按幅度/时间累计的代价。保留硬终止作为底线，不能只靠一个突然的-10切断单调正奖励。

**问题二：门槛奖励不等于持续阻碍。**累计1.5秒达标后，若退出干扰并安全等待终点，仍可获得+4。若研究目标是持续干扰，应加入持续性或目标影响积分指标，而非只有最低达标门槛。

**问题三：强制动规则已经改变。**当前并非所有<-3m/s²持续.4秒都越级：它还要求当时ell超过35%。这一修改可以减少目标自身短暂制动带来的误罚，但也意味着强制动本身不再充分否定轻度标签。研究表述应与代码一致。可考虑相对正常参考的额外制动量，而不是只用绝对制动阈值和速度损失的二元组合。

**问题四：轻度带与配置边界未完全统一。**m的上界35%写死，越级上界来自mild_excess_threshold。调整后可能出现“仍有轻度奖励但已进入越级计时”或“无轻度奖励却未越级”的区间。可以有意设计缓冲区，但必须明确，不能把它当成同一个可调等级阈值。

**任务可达性：**follow族的对抗车已在前方，有机会逐渐减速；adjacent族还须先形成影响。目标允许换道，因此简单慢行可能被绕过。L1应按场景族报告，不因长期没有效果就只加大速度损失权重。

## 5. L2：探索链条长且多个信号不一致

完整事件链为：A主动入目标车道→位于前方→满足横向/航向对齐并维持align_duration→当时THW在[.3,1.2]→一秒内目标有反应→整个T无碰撞，且事件后至少观察1秒。

### 5.1 首个有效事件之前引导稀疏

h必须在geometric_cut为真后才激活。几何切入之前，L2主要依赖d，无法直接告诉网络应如何横向移动。普通驾驶初始化本来倾向于稳定跟车，可能长期停留在非攻击行为附近。

现有共同驾驶初始化pilot的验证cut_count长期为0，支持瓶颈在事件链前段。不能据此断言唯一原因是奖励稀疏，还需排查探索尺度、基础策略支持范围及观测历史。

### 5.2 密集风险与事件窗口方向不一致

h在THW<1.5秒为正，且THW越小越大；事件仅接受.3–1.2秒。

例如目标18m/s、间距5m时THW约.278秒，事件不接受，h却约.815；间距2m时THW约.111秒，h约.926。过小的非碰撞间距可能获得更高密集奖励，但不满足成功定义。1.2–1.5秒也有正密集奖励但无事件资格。

因此h不能简单叫作“更高别车质量”。建议将其改成围绕有效事件区域的有界质量函数，明确是否允许事件区间外的准备收益及其强度。

### 5.3 h只需要曾经几何切入，不需要当前有效别车

geometric_cut一旦置真，回合内保持。此后只要回到前方关联和短THW，仍可得h，即使那次切入没有引起目标反应。策略可能学成“普通并线后贴近压制”，而非正式判据中的短间距切入。

效率项d同样可在没有合格切入时获得。a2b选中L2曾有约30.34m额外目标损失，但attack_success_rate和cut_count均0，说明辅助目标与主要事件可以分离。

### 5.4 只奖励首次有效事件

`if not self.cut_in`将有效别车锁为一次事件。cut_count可增加，但不直接进入奖励；cut_in为是否至少一次有效别车，并不是有效事件总数。当前目标合理对应“至少一次合格别车”，不对应“多次持续骚扰”。

如果研究要求重复攻击，应新增每次独立有效事件的状态机、冷却/恢复、重新入场条件、事件计数与有界奖金。不能直接奖励cut_count，否则几何反复横跳会代替实际目标影响。旧结果需要保留旧事件定义。

### 5.5 时间锚点和反应归因

候选窗口在完成对齐后打开，目标往往在横向接近过程中就开始制动。这时可能出现两类偏差：制动已改变THW，导致到对齐完成时失去资格；或历史brake_time和参考速度差已经存在，在窗口打开当刻立即满足反应条件。

后者不一定都是误报，因为制动确实可能由本次切入提前触发；但当前代码没有用“本次机动开始前的反应基线”区分旧干扰与新反应。应以威胁进入窗口、机动起点及响应增量共同定义，不能只扩大所有时间阈值。

目标lane_stable按相邻物理帧比较，不代表目标在完整切入窗口从未移动。目标的正确换道避让可能中断候选；这属于“目标成功避让”还是“攻击无效”，需要在评价定义中明确。

### 5.6 硬阈值可放大小行为变化

旧批L2 mutual seed43副本B在后段：平均cut_count=.5/.469/.469，而成功率50%/6.25%/46.875%，对应首次THW均值1.071/1.298/1.034秒。不能用次数稳定解释为策略收敛。

该证据与间距/反应阈值敏感一致，但平均值不能证明所有失败都由THW造成。需逐案例记录每个事件链门槛的失败原因，分别统计尝试、几何完成、间距合格、反应合格和最终成功。

## 6. L3：终点清楚，但探索、时间偏好与严重性需要分开

明确的+20目标碰撞，正常参考失效和无效行为不加奖，适合第一版二元攻击任务。相比L2，它不需要完成复杂的非碰撞事件链，目标更直接。

从普通驾驶初始化时，碰撞仍是稀疏事件。L3的h沿用别车后的前方短THW，偏向某一种攻击路径，对直接侧向接触或其他接触机制未必有帮助。

折扣后，同样成功的早碰撞通常比晚碰撞回报高。因此实际优化的是“折扣下发生目标碰撞”，隐含追求更早发生。若评价只看20秒内成功概率，则训练与评价对时间的偏好不完全相同。

当前没有按碰撞强度加权。接触方位为几何代理，不是事故损害；高成功率说明找到接触目标的策略，不说明找到最严重或最能暴露目标决策缺陷的事故。

如果策略池希望有不同碰撞机制，仅靠统一+20可能使模型都选择最容易的模式。应以行为描述符归档或显式机制目标维护多样性，不靠不同seed的模型数证明。

## 7. 新几何势函数的完整分析

最新环境增加了分等级Phi：L1偏向近距离前方位置；L2偏向目标THW带或邻道超车准备区；L3偏向纵横向接触接近。a2c权重.5，旧矩阵多为0。

### 7.1 不是所有状态都有引导

L1同道起点保险杠间距约30–50m，Phi仅在小于15m时为正，初始一大片区域为0。L2前方分支需要THW已经进入.3–1.2范围；后方准备分支还要求相邻车道、距后方不超过15m且比目标快2m/s，而常规初始速度差最多1m/s。

因此“增加Phi”不等于“从普通驾驶出发一路有密集引导”。仍需检查每个起点到攻击区的整条路径是否存在可辨识进度信号。

### 7.2 不同阶段的Phi高度不一致

L2前方THW带内的两个线性因子乘积最高.25，而后方准备分支最高可接近1。成功接近目标区时Phi可能下降，短期反馈方向不直观。标准势差的长期理论性质与有限样本中容易学习不是同一件事。

### 7.3 势差的数学含义

对F_t=gamma*Phi_(t+1)-Phi_t，折扣求和为：

```text
Σ gamma^t*F_t = -Phi_0 + gamma^N*Phi_N
```

当前真正终止Phi_N=0。如果起点Phi_0=0，完整回合折扣势差总和严格为0。它可以重新分配短期信用、辅助有限样本价值学习，但不会凭空把原本同样失败的轨迹变成不同的真实终局收益。

起点Phi不必强制为0：对给定初始状态，-Phi_0是与后续动作无关的常数。为了全部起点严格为0而造出大片平坦区，并不是势函数方法的必要要求。

新增Phi的验证应同时看分量、事件到达率和真正成功率，不能只展示某段正势差。

## 8. 反事实速度、空间关系和影响范围

速度损失d与最终进度损失不是同一个量：前者衡量瞬时差异，后者体现全时窗积分。参考速度变化且存在clip/分母下限时，两者不严格成比例。不能把所有累计d叫作最终距离效用。

front当前为纵向保险杠间距>0且横向中心差<2m，不是严格的IDM实际前车责任关系，也未按完整车辆姿态投影。对于大角度攻击或正在换道时，它是近似几何关系。该近似可用于轻量原型，但应对典型轨迹校验。

L1的m需要front，主d却不要求front；所以可由其他方式制造目标损失。若强调特定行为，辅助影响项应与行为有效性/阶段关联，或在评价中明确这些其他机制是否接受。

参考失效会产生-20并终止，即将正常对照自身失效变为代理负奖励。建议使用预冻结的统一场景校准保证参考可靠；不要让网络为与自身动作无关的对照错误负责，也不能在看到测试效果后任意删案例。

## 9. 观测与奖励状态不完全匹配

22维中有几何切入标记、连续front/低速/强制动时间，但没有累计blocking_time、实际cut_in标记、cut_event_time或excess_time。奖励和终止又依赖这些历史。

两个物理位置速度相同的观测，可能因为历史累计不同而具有不同成功前景。前馈actor/critic会面临部分可观测的任务状态。该问题不意味着PPO必然无法学习，但可能增加价值估计噪声和阶段行为混淆。

可选处理：加入可由自身观测历史计算的阶段信息；使用记忆网络；或给训练critic提供完整奖励状态、actor仍限制为可获得信息。涉及正常参考的内部量不能无说明地塞进执行actor。

## 10. 权重、折扣和终止风险

dt/T归一化合理，但它降低了首次事件之前密集信号的绝对量级；一次L2事件+2及终止+5占主导。这适合已经能产生候选机动的初始化，对纯普通驾驶初始化则可能探索困难。

gamma=.99、5Hz：约10秒后的奖励权重为.605，接近20秒为.370。L1/L2终止成功奖金会明显折扣；晚发生的失败成本也被折扣。有限负奖励不是安全/等级约束的数学保证。

降低全部惩罚可能帮助探索，也可能破坏等级；增加事件奖金可能更重稀疏性。不能未经事件链诊断就只调这两个方向。PPO使用标准化优势，奖励整体放大也不等于同比增强actor学习，critic损失与优化平衡会变化。

## 11. 选模与研究目标

当前rank_report要求baseline全有效，invalid/collision/grade_violation各不超过12.5%，随后优先attack_success_rate、再看utility。L3不以碰撞为失败。

优点是先排除明显无效策略、再按攻击表现选。局限是：

- eligible只是资格阈值，不代表成功率>0，零攻击模型也可eligible=true。
- 对L1/L2允许最高12.5%失败，与“严格非碰撞”不是同一承诺。
- L1/L2评价只要达到最低事件一次，不能区分重复攻击或长时间阻碍。
- L2没有有效事件次数，无法按持续骚扰选模。
- 全程最优selected可能来自互学习前或第一次更新，不能据此归因互学习。

需先固定研究主指标和容许失败水平，再匹配reward与选模。始终同时展示末次模型和验证最优模型，不用一次好结果代替稳定性。

## 12. 修改优先级建议

| 优先级 | 建议 | 目的 |
|---|---|---|
| P0 | 明确L2是至少一次还是重复别车 | 防止奖励和研究问题不一致 |
| P0 | 给每次切入记录门槛通过/失败原因 | 区分探索不足、间距、对齐、目标反应与碰撞 |
| P0 | 统一L2间距质量与事件范围 | 去掉“越小越奖、过小却不算成功”的方向矛盾 |
| P0 | 使L1主要影响奖励在轻度范围内达到峰值 | 不让主正奖励驱动越级 |
| P1 | 连续、阶段一致的几何进度；核对整个初始到目标路径 | 减少探索平坦区和阶段回落 |
| P1 | 调整切入与制动反应的事件时间锚点 | 防止过晚开窗与历史反应复用 |
| P1 | 补任务历史观测或critic任务状态 | 降低隐藏奖励状态导致的估值混淆 |
| P1 | 将资格、单次/重复成功、末次/selected分开报告 | 避免错误归因 |
| P2 | 冻结后做单因素权重/阈值消融 | 用证据敲定参数 |

如果定义重复L2，应增加重新入场、冷却与目标反应恢复规则，每次必须是新的有效事件；可采用递减奖金和事件上限。同步增加有效事件数、有效率和至少两次成功率。不能用现有cut_count简单乘正系数。

## 13. 最小验证清单

1. 正常驾驶、温和阻碍、危险切入、贴近但不切入、无效横跳、目标接触、出界分别验证奖励排序。
2. 对THW上下边界、对齐前后、目标先制动和目标主动换道进行配对轨迹核查。

4. 按场景族报告事件链到达率，检查普通初始化是否能进入第一次有效事件。
