# Hybrid Mut-PPO Implementation Plan

> **For agentic workers:** Use executing-plans to implement the approved design task by task. Work in the current workspace; isolate the implementation in a new package. Do not delegate.

**Goal:** 将神经网络控制改为连续纵向加速度和离散换道决策，保留同任务双副本互学习，提供训练、恢复、独立评估与操作说明。

**Architecture:** 新增 `PythonAPI/examples/highway_hybrid/`，复用冻结的 straight 场景、物理引擎和等级事件奖励。通过原生横向控制器执行目标车道；网络独立输出 Gaussian 和 masked Categorical，PPO 使用联合对数概率。控制器目标车道、执行状态和动作掩码纳入观测，检查点协议隔离。

**Tech Stack:** Python、PyTorch、Gymnasium、highway-env、TensorBoard、unittest。

## 实施验证

- 混合动作测试及原有相关回归通过，另验证控制器回正计时在观测中可区分。
- 独立只读审查未发现重要正确性问题。
- 已完成真实命令行512步短回合 smoke，实际启用两个互学习系数0.02，生成检查点、TensorBoard与独立评估产物。该结果只验证流程，不代表攻击训练有效。
- 已生成18组主实验配置。无梯度随机采样初查显示换道和几何切入事件可以被触发，但有效切入仍需训练验证；不得把探索诊断当成训练成功。
- 默认每个 rollout 从新场景开始，未完成回合前缀用价值自举；只有完整回合进入 episode 统计。主协议512步 rollout 对20秒回合通常含多个完整回合。

## 约束与验证

1. 任意阶段均由网络选择车道，不将三级攻击脚本写进执行器。
2. 两副本只在同级任务内互学习，independent 保持同预算双副本选模。
3. KL 使用同一状态、同一合法动作集合；PPO 存储并复用采样掩码。
4. 换道期间仍允许加减速；横向锁定直到靠近目标车道中心且航向回正。
5. 不将短程 smoke 当作奖励或算法有效性证明；新旧动作协议分别统计。
6. 不复用旧 Gaussian 转向头检查点，避免动作语义混用。
