# 一对一直道实验执行计划（30 run 矩阵）

日期：2026-11-09。本文是执行口径，配合[实施计划与任务分解](一对一直道_实施计划与任务分解_20261109.md)与[实现决策与补齐范围](一对一直道_实现决策与补齐范围_20261109.md)。所有命令从 `PythonAPI/examples` 执行，Python 用仓库 venv（Windows：`D:\study\yan2\CARLA_0.9.16\venv\Scripts\python.exe`）。

## 1. 研究矩阵（冻结）

| 研究块 | 配置 | seed | 新 run | 输出目录 |
|---|---|---:|---:|---|
| 主对比 | L1/L2/L3 × independent/mutual | 42/43/44 | 18 | `runs/straight_v1/train/main/<name>` |
| β 敏感性 | L2 mutual，β=0.005/0.08 | 42/43/44 | 6 | `runs/straight_v1/train/beta/<name>` |
| 奖励消融 | L2 mutual，no_risk / no_event | 42/43/44 | 6 | `runs/straight_v1/train/reward/<name>` |

**复用（不重训，报告表注说明）**：β=0 → 主对比 `L2_independent_s*`；β=0.02 → 主对比 `L2_mutual_s*`；消融 full → 主对比 `L2_mutual_s*`。

每个 run 的 200k 是 **A+B 合计决策步**（每副本约 100k）。基础初始化按 seed 一份（`runs/straight_v1/base_s<seed>/driver.pt`），同 seed 全部配置共享；预训练示范数量与成本在 qualification/manifest 中记录。

## 2. 执行顺序与决策点

### 阶段 0：环境校准（T0+0–2h）

- `python -m unittest discover -s highwaytest/tests -p "test_straight*.py" -v` 全绿。
- `python -m highwaytest.straight calibrate --cases 8 --output runs/straight_v1/calibration.json`：检查 normal/block/cut/collision 四个脚本在 L1/L2/L3 下的 `baseline_valid`、`success`、`grade_violation`、reward 分量累计。
- **决策点**：任一等级脚本目标事件不可达（如 L1 block 从未成功、正常参考自发失效）→ 回到开发集修场景/阈值，不展开矩阵。脚本可达不代表策略可学。

### 阶段 1：基础初始化（T0+2–4h）

- 三个 seed 各跑 `bootstrap --seed <s> --episodes 128 --epochs 40 --output runs/straight_v1/base_s<s>`，产出合格 `driver.pt`（资格：成功≥90%、出界≤5%、示范换道数>0、换道验证≥50%）。不合格时按实施计划 Task 1 修复或走 level-0 PPO 备选。
- **决策点**：三个 seed 的 driver.pt 必须全部合格，否则矩阵不启动。

### 阶段 2：小预算预实验（T0+4–8h）

- L1/L2/L3 × mutual × s42 各跑一个 `total_steps=20000` 的短 run（独立目录 `runs/straight_v1/pilot/<name>`，不与正式混表），观察：各等级是否出现目标行为趋势（blocking_time / cut_in 率 / 目标碰撞率）、失败原因、事件频次、单 run 端到端吞吐（decisions/s，含训练期评估）。
- 用实测吞吐决定 batch `--jobs`：先 1，再试 2；小网络不保证 GPU 更快，不按 GPU 型号承诺时间。
- **决策点**：若 20k 步后某等级完全没有目标事件，先查可达性/探索/奖励尺度，不直接展开该等级的 6 个 run。

### 阶段 3：主对比 18 run（T0+8–24h，最高优先级）

```powershell
& ./highwaytest/scripts/run_straight.ps1 -Steps 200000 -Seeds 42,43,44 -Jobs <实测>
```

脚本自动完成：plan/check 主矩阵、bootstrap（已存在则跳过）、batch main。训练日志 `train/main/batch_logs/`，TensorBoard `tensorboard --logdir runs/straight_v1/train/main`。

### 阶段 4：β 与消融 12 run（T0+24–36h）

```powershell
& $py -m highwaytest.straight batch --configs highwaytest/configs/straight_beta_v2 --output runs/straight_v1/train/beta --jobs <实测>
& $py -m highwaytest.straight batch --configs highwaytest/configs/straight_reward_v2 --output runs/straight_v1/train/reward --jobs <实测>
```

**时间不足的删减顺序**（《两日》§9 优先级）：先删消融 6，再删 β 6；主对比 18 的完整 seed 块永远保留，不得只给某一组更多训练或选择性补有利结果。

### 阶段 5：冻结后最终 test（T0+36–42h）

- 冻结：奖励、事件阈值、观测、选模规则、test 案例（种子偏移 3m 起 100 个）在此前全部确定，test 不参与任何选择。
- 对 `train/{main,beta,reward}/*/selected.pt` 逐个：`evaluate --checkpoint <run>/selected.pt --split test --cases 100 --output <run>/test`（evaluate 自带 source_changed 检查；冻结后源码不得再改）。
- 正常参考失效的 run（baseline_valid_rate<1）不进入汇总，单列报告。

### 阶段 6：汇总、策略池与图（T0+42–48h）

```powershell
& $py -m highwaytest.straight report --runs runs/straight_v1/train/main runs/straight_v1/train/beta runs/straight_v1/train/reward --output runs/straight_v1/comparison
& $py -m highwaytest.straight pool  --runs runs/straight_v1/train/main --output runs/straight_v1/pool.json
& $py -m highwaytest.straight matrix --runs runs/straight_v1/train/main --output runs/straight_v1/matrix.json
```

report 产出：逐 seed CSV 长表、均值/样本标准差 JSON、图 1–5+7 PNG/PDF（λ 图 6 在 figures_note.json 注明本轮未运行）。pool 只覆盖主对比 18 run，从 selection 合格成员按等级选代表（描述符门控），未学成等级列入 missing。matrix 输出"训练意图×实际行为"一致性热力图。

## 3. 预算估算

- 训练：30 run × 200k = 6.0m 合计决策步。按实测吞吐：100 步/s ≈ 16.7h，300 步/s ≈ 5.6h（预算算式，非承诺）。
- 训练期评估：每 20k 步评估 A/B 各 32 selection 案例，单 run ≈ 96k 决策步（~48% 训练量），已含在上述吞吐实测内。
- 最终 test：30 × 100 × 100 ≈ 300k 决策步 + 轨迹导出，约 1–2h。
- bootstrap 与 pilot 另计。

## 4. 失败模式速查（详见《两日》§13）

| 现象 | 处理 |
|---|---|
| 正常参考自己停车/碰撞 | 开发集修正统一场景分布并冻结，不事后筛 test |
| 只会碰撞/学不到别车 | 事件奖励与安全终止、分量尺度；确保失败无成功奖金 |
| L1 只学无关停车 | 场景初始化与前方关联、参考校准 |
| 互学习无效果 | 如实报告；检查 β×KL、教师快照、选中策略更新历史 |
| 回报涨但攻击指标不涨 | 完整任务指标诊断，冻结前改设计 |
| 算力不足 | 按 §2 阶段 4 的删减顺序执行 |

## 5. 报告口径红线

- 三等级 raw return 不横向比较；L1/L2 低碰撞是目标、L3 高有效目标碰撞是目标，分面板展示。
- 训练横轴一律 A+B 合计步；标题写"自定义直道对抗任务"，不写官方 Highway 基准。
- A/B 副本不是两种攻击、不是两个 seed；跨 seed 结论只报 3 seed 均值/样本 SD/原始点。
- 互学习收益的机制结论本轮限定 L2-A（《分级》§12）；若 β 消融在 L1/L3 没有对照，不宣称全等级受益。
