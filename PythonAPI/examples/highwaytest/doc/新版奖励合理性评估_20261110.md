# 新版奖励合理性评估

日期：2026-11-10。评审对象为本次读取的straight/rewards.py、config.py、environment.py、runner.py及环境测试。只评估，不修改用户训练代码或重跑正式训练。

## 结论

新版本比上一版明显改善，目标方向基本合理，可继续开发预实验。正式重复别车实验前，应先处理“新事件反应独立性”及“最后一次事件覆盖成功资格”两项语义问题；随后检查几何引导、历史观测、聚合诊断及选模。现有测试通过不能直接证明可学性和鲁棒性。

## 已改进的地方

| 旧问题 | 新实现 | 评价 |
|---|---|---|
| L1持续追求更大速度损失 | ell乘轻度区间梯形band，超出后衰减至0 | 主奖励推动越级的冲突明显减弱 |
| L2越贴近越有风险奖励 | h=band(THW,.3,1.2,.15) | 有效区间内得最高分，过近下降，方向合理 |
| L2只奖第一次 | 每个反应确认事件计数、发+2，最多4次 | 已真正改为重复事件奖励 |
| 成功只需一次 | cut_success_min=2 | 更符合反复别车目标 |
| 网络不知道事件次数 | 22→24维，新增计数及距上次事件时间 | 改善阶段可观测性 |
| 不知道卡在哪个判据 | candidates/geometric/thw_ok/thw_miss/react_hit/react_miss | 有助于定位，但尚非闭合漏斗 |
| 选模忽视有效次数 | L2次指标增加.05*cut_count | 方向正确，优先级仍以成功率为主 |

## 新版实际公式

令B(x;l,u,w)为梯形函数：区间[l,u]内为1，两侧宽w内线性衰减到0。逐步项乘dt/T，事件项不乘。

```text
d=clip(ell,-1,1)
d_band=clip(ell,0,1)*B(ell;.10,.35,.05)
h=1[曾几何切入且当前前方关联]*B(THW;.3,1.2,.15)

L1: (dt/T)*(2*effect_weight*d_band + mild -.05*control_cost)
    +4*event_weight*success -20*collision -10*grade_violation -20*invalid
L2: (dt/T)*(effect_weight*d +2*risk_weight*h -.05*control_cost)
    +2*event_weight*每次有效事件（前cut_reward_cap次）
    +5*event_weight*success -20*collision -20*invalid
L3: (dt/T)*(.2*effect_weight*d+.5*risk_weight*h-.05*control_cost)
    +20*event_weight*有效目标碰撞 -20*invalid
```

无效、碰撞、越级和普通事件仍按原优先级处理，不能同帧重复领取成功奖金。几何势差仍单独追加，其效力取决于实际配置中的geometry_weight。

## L1判断

新主项在轻度带内有收益，超出后下降，基本修复旧版主奖励鼓励持续严重减速的矛盾。状态机探针中，ell为.25/.35/.36/.4/.5时，未乘dt/T的密集值为1.5/1.7/.576/0/0（front=true、无强制动）。

仍需留意：

1. mild本身是硬指示函数，.35两侧仍有明显跳变；“用了band”不代表整体完全平滑。
2. .35是轻度奖励硬编码边界，mild_excess_threshold是可配置越级边界，两者调整时要说明关系。
3. 成功仍是累计1.5秒，不是持续整个回合；若强调持续阻碍，需补充持续性指标。
4. 严重损失现在正收益变为0，不是持续负代价；连续越级计时仍可能被短暂恢复打断。是否被实际利用需轨迹验证。
5. 累计blocking_time和excess_time仍未进入前馈观测，估值依然存在部分历史不可观测。

整体：值得保留当前改进，优先用边界轨迹验证，而不是立即增加更多奖励项。

## L2重复事件：需要优先修复的两处问题

### 1. 新事件不一定包含新目标反应

当前每个几何合格的重新入场都会打开窗口，窗口内满足历史brake_time或相对正常参考速度损失>=3即可确认。重置brake_time能减少部分复用，但相对参考速度差仍可一直存在。

额外状态机探针：目标一直14m/s、参考一直18m/s、加速度一直0；给出两次独立入场与对齐信号，cut_count仍从1变成2。第二次没有新增速度损失，也没有新制动，仍获得+2。

这是状态机合成帧证据，不代表网络已在实际交通中利用。它说明“新机动+旧速度损失”可以被计为新有效反应。

建议保存每次机动前的速度、加速度/制动与参考损失基线；要求本次窗口内有新增反应，或明确将其定义为“对已受阻目标再次施压”，不要继续称为独立制动事件。重新入场的确由环境lane-crossing信号约束，不能说代码完全不需要离开再进入；欠缺的是反应恢复/独立性与显式冷却。

### 2. 多一次有效事件可撤销已满足的成功

终点资格现在要求cut_count>=2，同时time-last_cut_time>=1。last_cut_time每次都更新。

可复现探针：T=3秒，前两次有效事件发生于约.5和1秒；之后等待，回合成功。若2.5秒再完成第三次，cut_count=3，但终点距最后一次只有.5秒，整回合失败。

如果定义是“至少两次已完成观察期的独立有效别车”，这就是非单调目标：更多有效事件反而取消成功。建议统计每个事件独立存活/观察满1秒后的qualified_count，成功看qualified_count>=2；或记录达成第2次合格事件的时刻。全局碰撞仍然应撤销成功。

若确实要求“最后一次也必须观察满1秒”，则应停止在最后一秒接收新攻击，或在规则里明确它是整回合结束条件。不能同时隐含“越多越好”和“多做一次可能全盘失败”而不解释。

## L2其他合理性与剩余问题

梯形h解决了原先THW趋近0奖励最高的问题。.3–1.2秒平台都得1，两侧缓冲有部分奖励，属于探索塑形，不能把缓冲区当作事件合格区。

但h仍由“曾几何切入”激活，不要求有效反应；效率d也仍可在没有切入时获得。因此普通并线后跟随或其他交通阻碍仍能获得辅助收益，主要事件与辅助目标未完全一致。

对齐后才判断THW、再看一秒目标反应的时序没有改变。目标可能在对齐完成前已制动，从而改变间距或留下旧反应。新增重复事件使这个时间归因问题更重要。

cut_count语义已经改变：以前是几何次数，现在是反应确认次数。几何次数应读cut_diag.geometric。cut_in仍是“至少一次”，正式attack_success现在至少两次且满足终止条件。旧图不能继续沿用新字段解释。

最多4次事件奖金限制刷取，设计合理；但等额+2会在上限前持续鼓励增加机动。如果目标是高质量重复干扰，可考虑递减奖励或质量权重，并重新检查折扣下的碰撞风险权衡。

## 24维观测与诊断

新增有效事件计数和距上次事件时间，确实帮助网络识别“已经做了几次”及“是否快满足观察期”。但仍没有完整的累计轻度时间、越级时间和当前反应窗口状态，不应宣称已完全恢复马尔可夫性。

切入次数被cap归一化是可行的，但cut_success_min应与计数表达范围一致。当前validate没有要求cut_success_min<=cut_reward_cap，也没有严格要求二者为int；若允许这些组合，需要明确语义，否则应拒绝。

cut_diag逐episode保存有价值。但当前evaluate_model的overall聚合及TensorBoard白名单未聚合这些嵌套诊断，因此默认面板不能直接显示全链路通过率。

目标换道或新候选覆盖可能清除待确认窗口，却没有记录对应的abort原因；candidates与后续阶段不能按严格闭合漏斗相减。应补未对齐、目标换道中断、超时等原因，才能区分“策略没完成”和“检测中断”。

## 几何引导与L3

本次主要更新在rewards.py，environment.py中的阶段势函数、准备区门槛仍基本沿用之前版本。新增band和重复事件并不自动解决普通驾驶到首次切入之间的零信号区。L2的post-cut势函数只在较窄THW区内为正，overtake准备分支还有速度优势门槛；完整回合终止势值仍为0。

L3仍是二元有效目标碰撞任务，终点清楚，但新增的h带形仅调整辅助信号。它不奖励碰撞强度、责任或特定机制，不能据此声称发现更严重或更多样的事故。

## 验证范围与版本边界

本次执行`python -m unittest highwaytest.tests.test_straight_environment -v`：25项通过，1.215秒。额外只读状态机探针确认了上述两项未被现有测试覆盖的边界问题。

已有脚本reachability测试通过，不代表同一回合真正两次独立反应的全部时序都合理，也不代表PPO已学成重复别车。

新版obs由22变24，L2成功由一次变至少两次，cut_count由几何计数变有效计数。这是任务语义变化，旧成功率不能作为新版直接对照；旧22维初始化需要明确适配或重建。运行中进程不因磁盘改动自动更新奖励，应以对应run的config、source快照和记录的源码SHA确定实际版本。

总体建议：保留L1带形、L2带形及重复目标；先修每次反应归因与终点计数，再补事件级诊断和少量物理校准，最后以新协议身份开展PPO及互学习对比。
