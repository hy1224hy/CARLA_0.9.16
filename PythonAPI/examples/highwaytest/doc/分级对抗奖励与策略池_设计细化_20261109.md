# 分级对抗奖励与多样策略池：奖励及互学习设计

日期：2026-11-09。本文根据用户最新说明修订研究建模；只给出研究方案，没有修改训练程序或启动实验。数值为开发集预实验候选，不是已经验证的最优参数。

具体实现候选：见[一对一直道观测、动作与三级奖励V1](一对一直道_观测动作与三级奖励V1_20261109.md)，其中按允许目标换道的设定细化22维观测、连续动作、事件时序和开发集校准。若与本文较早的初始阈值不同，以V1中的候选及最终开发集冻结记录为准。

## 1. 研究目标与互学习的准确含义

最终目标：得到一个覆盖轻度交通阻碍、中度非碰撞干扰、碰撞攻击的多样对抗策略池。

用户明确指定的互学习是：**同一奖励配置、同一策略类型，启动两个同构训练副本，通过互学习损失对齐，改善该类策略的鲁棒性。**

因此采用：

```text
某奖励配置z → 训练副本A ⇄ 训练副本B → 选出该配置的策略 → 策略池
另一奖励配置z' → 另一对副本A' ⇄ B' → 另一类策略 → 策略池
```

不同攻击等级、不同目标行为之间不计算互学习损失。副本A/B不是策略池中两种行为；它们是同一类策略的两个训练过程。策略池多样性来自不同奖励配置与行为筛选，互学习用于改善各配置内部的训练。

“相同训练”指网络、任务、奖励、优化器设置和采样分布相同；训练随机流应独立。如果参数、环境随机数、动作采样、批次顺序全部相同，两个副本可能始终一致，互学习KL接近零，难以产生额外作用。

本轮主算法不额外强制加入质量门控。上一份文档中的选择性门控属于可选扩展，不是用户定义的互学习所必需。

## 2. 等级与行为标签分开描述

建议以z=(ℓ,b,η)描述一个策略配置：

- ℓ：期望攻击等级；
- b：行为目标/机制；
- η：该目标内部的参数，如阻碍程度、切入间距或持续时间。

| 设计等级 | 主要目标 | 指定目标碰撞 | 典型行为 |
|---|---|---|---|
| L1 轻度 | 正常目标车出现持续、有限的效率损失 | 惩罚，不能作为L1成功 | 平缓慢行阻碍、温和速度扰动 |
| L2 中度 | 目标出现显著避让、制动或非碰撞停车 | 惩罚，不能作为L2成功 | 短间距切入、切入后减速压制 |
| L3 高度 | 在物理有效条件下与指定目标形成碰撞 | 正奖励，是本级目标 | 侧向/纵向碰撞模式 |

这是本研究自定义的事件层级，不等同于事故损害或法律责任等级。特别是碰撞不能仅凭发生与否推断伤害程度；简化仿真中的相对速度也只能作为代理量。

逼停可放入L2的强非碰撞子类型，不能与“轻微慢速阻碍”混为一类。

训练配置的标签与实际行为必须分开保存。L1配置如果在测试中撞车，应记录为“意图L1、实际出现碰撞”，不能因为配置名字是L1就认为它属于轻度。

## 3. 推荐的建模路线

首轮采用独立奖励配置、独立网络与独立副本对。每种配置的训练器共享实现，权重和事件定义由配置控制。

可选路线：

| 路线 | 优点 | 当前限制 |
|---|---|---|
| 多奖励配置，各自训练一对副本 | 清楚可控、容易定位奖励问题、避免跨等级训练干扰 | 模型和任务数随配置增加 |
| 条件策略π(a|o,z)，整体维护两个训练副本 | 共享模型、便于连续调节 | 多任务权衡、critic条件化和奖励尺度更复杂 |
| 在目标奖励上叠加自动技能发现 | 有机会发现额外行为 | 新增判别器/调参与无效多样性问题 |

两天方案采用第一条。后续可以用相同z定义扩展条件策略，首轮不必增加额外网络。

不能只用一个“攻击系数”放大同一个奖励。放大延迟奖励可能主要改变阻碍程度，不能保证出现碰撞和别车等不同机制。

## 4. 公共奖励特征与有效事件

固定评价时窗T=20s，策略间隔Δt=0.2s，δ=Δt/T=0.01。目标为V，对抗车为A。所有时间量在物理子步累计。

### 4.1 正常参考与目标损失

为相同初始案例运行正常交通参考C1，将可学习A替换成冻结正常规则车；C2使用当前对抗策略。目标控制器、初始状态、道路一致。

```text
d_t = clip((vV_C1(t)-vV_C2(t))/vscale, -1, 1)
D   = Σ δ*d_t
```

候选vscale=20m/s。保留负值。参考轨迹不进入actor输入；确定性参考可以缓存。

碰撞即终止后，不能把目标速度置0、补足剩余时间来继续刷效率损失。碰撞组以事件/时间指标评价，非碰撞组才使用完整时窗额外进度损失。

### 4.2 有效阻碍b_t

b_t应由三类条件共同组成：A确实位于目标前方并影响其行驶、A处于期望慢速带、V相对参考出现实际损失。

可写为：

```text
b_t = front_relation(A,V)
      * slow_band_score(vA/vref)
      * clip((vV_C1-vV_C2)/vscale,0,1)
```

front_relation同时考虑同一行驶带、正的保险杠间距和相关距离，不使用“本车速度低”替代有效阻碍。slow_band_score在候选0.5–0.8的相对速度带内较高，并对停车或过度减速下降。

这使离目标很远的原地停车、在无关车道慢行不容易获得阻碍收益。

### 4.3 别车事件f_cut

候选判据：原先相邻车道→切入目标前方→基本完成横向/航向对齐→短窗口内目标出现明显减速或参考相对速度损失。

- 使用车身保险杠间距，不用车中心距离代替。
- 候选切入时距0.3–1.2s；具体阈值经开发案例校准。
- 候选目标制动<-2m/s²，或相对参考速度损失≥3m/s。
- 每回合仅首次达成计一次f_cut；后续反复横跳不重复发奖。
- 若整个回合发生目标碰撞，L2最终成功为0，即使之前曾完成切入。

### 4.4 交互风险h_t

可采用相关行驶带内的TTC、THW或目标制动强度构成有界h_t∈[0,1]。

纵向TTC仅在有正保险杠间距、车辆确实接近且行驶路径相关时定义；不接近时设风险为0。相邻车道并行不能只因为纵向距离小就获得高风险分。

别车子类型可仅在有效切入后激活风险项，避免奖励目标后方的无关追逐。逼停子类型不能仅依赖TTC：两车都慢下来时TTC可能不小，但实际压制已经发生。

### 4.5 指定目标碰撞c_t

```text
c_t = 1[首次发生符合本配置接触类型的A—V碰撞，且碰撞前状态物理有效]
```

L3奖励这个事件。L1/L2的c_t采用更广的定义：任何A—V首次碰撞都要惩罚，不因接触类型不匹配而免罚。撞墙、撞到无关对象不能自动得到同样奖励。初始重叠或其他初始化错误不构成策略成功。

本次核对的Highway-env 1.10.2源码中，Road.step逐对处理碰撞，车辆crashed标记本身不保存完整碰撞对象身份。实现时应记录碰撞对、首次事件和碰撞前状态，不能用any(vehicle.crashed)直接替代指定目标事件。

若按接触方位区分侧向/纵向，应注明是几何代理分类，不能宣称得到真实接触力或完整事故责任。

### 4.6 公共无效行为与控制成本

共同保留道路范围、速度/加速度/转向边界；不通过出界、逆向或非目标碰撞来制造攻击成功。

动作变化成本应较小，不能把L3强行拉回普通驾驶。正常车道变换不应被统一当成出界惩罚，否则L2别车目标本身会被抵消。

## 5. 级别约束：避免轻度策略也追求严重攻击

仅设置权重不能可靠限定等级，建议同时使用训练惩罚和入池资格。

L1最大化有效效率损失，但要求目标碰撞率低、没有明显别车/强制动/持续逼停。L2最大化指定非碰撞交互成功，但要求目标碰撞率低。L3最大化指定目标碰撞成功，并满足基本物理有效性。

可用约束目标表示L1：

```text
max E[J_block]
s.t. P(C_target)≤εc，P(E_above_L1)≤εh
```

首轮不必实现复杂约束优化器，可以采用固定惩罚、等级越界检测和验证资格。达到更高等级事件时，L1不得领取轻度成功奖金；可立即结束并标记等级越界。

固定惩罚不能构成约束保证。必须在独立验证/测试案例上测量实际越界率。资格阈值在开发集冻结，不能看最终test再调整。

## 6. 第一轮可实现的奖励模板

公共形式：

```text
r_t(z) = δ*[wd(z)*d_t + wb(z)*b_t + wh(z)*h_t - wu*u_t]
       + wf(z)*f_cut,t
       + Bz*1[回合结束且满足z的完整成功条件]
       + wc(z)*c_t
       - Pinvalid*invalid_event_t
       - Pgrade*grade_violation_t
```

δ只乘逐步的有界密集项。事件项只发一次。所有终止奖金在资格确认后发放。早期结束案例要保留真正终止语义，不进行剩余时窗伪造。

| 候选系数 | L1慢速阻碍 | L2别车/压制 | L3目标碰撞 |
|---|---:|---:|---:|
| wd：目标损失 | 2 | 1 | 0.2 |
| wb：有效慢行阻碍 | 1 | 0 | 0 |
| wh：相关交互风险 | 0 | 2 | 0.5 |
| wf：首次有效别车 | 0 | 2 | 0 |
| Bz：完整目标成功 | 4 | 5 | 0 |
| wc：目标碰撞（L3需匹配子类型） | -20 | -20 | +20 |
| Pinvalid：出界/非目标等无效事件 | 20 | 20 | 20 |
| Pgrade：非碰撞等级越界 | 10 | 按子类型定义 | 无需限制为低等级 |
| wu：控制变化成本 | 0.05 | 0.05 | 0.05 |

L3目标碰撞已经得到+20，不再重复领取通用成功奖金。同一步发生无效状态时，不发有效碰撞奖励。

L1/L2目标碰撞已经扣分，无需再把同一次碰撞重复计入grade_violation。grade_violation用于L1出现强非碰撞行为、或某子类型出现不符合其目标的更强行为。

L3如果需要按侧向/纵向细分，c_t应匹配该子类型。碰到同一目标但接触类型不同，记录为错类型事件，不自动当作该子类型成功。

以上数值仅为可解释的初始量级。每项密集奖励因δ归一化后，总量有界；事件奖金突出目标。还须检查γ折扣后最晚发生的失败惩罚，是否足以压过此前获得的密集收益。

探索困难时，可增加小权重势函数引导γΦz(s_next)-Φz(s)，Φz表示与本配置目标几何的接近程度。有限时窗终止势值应统一处理。不要加入大权重通用“本车高速行驶”奖励，否则慢行阻碍与逼停目标会受到抵消。

## 7. 三个等级的完整成功条件

### L1

候选：目标相对参考速度降低10%–35%，持续至少3s；A确实形成相关前方阻碍；无目标碰撞、无出界、无已定义的强别车或逼停事件。

温和速度扰动子类型还需对方速度变化确实随干扰增加；仅让A自身速度波动不算成功。扰动幅度与目标制动均受轻度资格限制。

### L2

短间距切入子类型：切入过程完整、目标有明显反应、整个时窗无碰撞。切入后的短暂接近但无目标反应，应降低质量或不计成功。

持续压制/逼停子类型：先形成前方干扰，再令原本正常行驶的目标低速或停车持续一定时间；正常参考同时仍在行驶；整个时窗无碰撞。

这一子类型允许A减速或停车，不能直接使用旧瓶颈协议“停车不超过3s、进度保持85%”作为共同资格。

### L3

指定目标碰撞事件和该子类型匹配，碰撞前状态满足统一物理有效性，终止并记录时间、接触方位、相对速度等。

L3不能使用“全回合无碰撞”作为门槛或选模条件，也不能沿用旧的“碰撞越少越好”质量分。是否低目标碰撞率在不同级别下含义相反。

## 8. 六个初始策略池槽位

| 槽位 | 目标行为 | 与同等级另一槽位的差别 |
|---|---|---|
| L1-A | 持续平缓慢行阻碍 | 稳定、较长时间的效率损失 |
| L1-B | 温和速度扰动造成交通波动 | 时间变化特征不同，仍不越过L1边界 |
| L2-A | 短间距切入并引起制动 | 以瞬时切入反应为主 |
| L2-B | 切入后的持续减速压制/逼停 | 以持续低速影响为主 |
| L3-A | 侧向接触类型的目标碰撞 | 接触方位与轨迹不同 |
| L3-B | 纵向接触类型的目标碰撞 | 接触方位与轨迹不同 |

每个槽位用独立奖励参数和成功条件训练一对副本。左右镜像可作为场景扩展，但不宜仅凭左/右镜像就宣称发现全新的攻击机制。

六个槽位是覆盖目标，不是已经获得六种策略。某槽位未学成应保留为空，不用相似策略复制填满。

## 9. 训练副本内部的互学习

对固定z，两个副本的目标是：

```text
LA(z) = LPPO,A(z) + β*E[o~DA(z)] KL(πA(.|o,z) || stopgrad(πB_snapshot(.|o,z)))
LB(z) = LPPO,B(z) + β*E[o~DB(z)] KL(πB(.|o,z) || stopgrad(πA_snapshot(.|o,z)))
```

两个方向分别在各自采样的观测上计算；在每个KL内部，双方输入完全相同。不能把πA(oA)与πB(oB)直接对齐。

双方PPO仍各自使用自己的on-policy轨迹。连续动作KL优先复用tanh前高斯分布实现。教师快照在更新窗口内冻结，梯度只更新当前副本。

可采用前10%训练步β=0、后10%线性增加、随后固定的安排；这是候选训练日程，所有等级采用统一规则。β控制同一奖励配置的对齐强度，攻击权重控制行为目标，两者分开记录。

输出采用统一验证程序选出的A或B，保存另一副本作训练记录。无需在执行时同时运行两副本，也无需把两个副本都算作池内不同攻击类型。

同配置副本对齐和不同配置间的行为差异可以同时存在；首轮不需要额外对跨等级模型施加“相互远离”的参数距离损失。

## 10. 如何筛选和证明多样性

每个候选checkpoint在同一套selection案例上计算行为描述符，例如：

```text
f(π) = [目标额外进度损失，干扰持续时间，平均速度比，
        切入次数/间距，目标最大制动，低速持续时间，
        目标碰撞率，接触类型分布]
```

使用行为和结果，不用网络参数距离作为核心多样性证据。不同随机seed或模型哈希也不能自动算行为多样。

筛选流程：

1. 检查该配置的成功率、物理有效率和等级越界率。
2. 根据实测描述符确认它属于对应行为槽位。
3. 比较已有同槽位成员；质量更好且行为相似时替换，不重复计数。
4. 只有行为差异达到预定阈值、且质量合格时，才增加同槽位额外成员。
5. 在selection上完成筛选后冻结策略池，最终test只评价，不继续挑选成员。

第一轮可按“等级×行为类型”手工归档，借鉴质量与多样性归档思想，但不声称实现完整MAP-Elites算法。

建议报告：

- 等级一致性矩阵：行是训练意图L1/L2/L3，列是实际无效/轻度/强非碰撞/目标碰撞。
- 六槽位覆盖率；每个槽位的成功率和有效率。
- 共享案例上的描述符距离矩阵，并同时展示描述符本身。
- 每个槽位至少一条代表轨迹和失败案例。
- 策略×不同规则目标参数/场景条件的交叉表现。

描述符在selection上归一化，尺度冻结后用于test。不只报告整体熵：均匀地生成许多无效行为也可能熵很高。

## 11. 鲁棒性与稳定性分别验证

互学习损失小只说明副本分布更接近，不证明攻击策略更鲁棒。

稳定性：不同独立训练seed之间的结果差异，以及固定验证案例上的后期性能回撤。

鲁棒性：改变初始间距、初速、规则目标的跟车参数、是否允许换道，或加入预先冻结的轻微观测扰动后，该槽位能否继续保持目标行为及等级。

对L1/L2，鲁棒性同时要求有效干扰和低等级越界；对L3，要求有效目标碰撞行为在不同条件下保持，而不是把碰撞率降低解释成攻击鲁棒性提高。

两个训练副本不是两个独立训练seed。一对副本的完整训练至少重复3个seed，才能初步描述跨训练重复的稳定性。

## 12. 两天内的范围建议

先完成每级一个代表行为：慢速阻碍、短间距别车、指定目标碰撞。奖励与判据有效后，再扩展其余三个槽位。

最小建池：6个奖励配置×3个独立训练seed=18次副本对训练，每次内部含A/B两个副本。每个配置经验证选出一类合格策略，不把副本数量当作多样性数量。

若保持原两天预算，可以先把互学习机制实验集中在L2-A：

| 实验 | 新增副本对run |
|---|---:|
| 六槽位均采用互学习，3 seed | 18 |
| L2-A无互学习双副本对照，3 seed | 3 |
| L2-A β新增0.005/0.08，3 seed；0与0.02复用 | 6 |
| L2-A去几何引导、去事件奖励，3 seed | 6 |
| 合计 | 33 |

这套预算只能把互学习收益的机制结论限定在L2-A，不能宣称已证明三个等级都受益。若要跨等级结论，应给L1/L3代表配置补齐相同对照；若要比较整体策略池覆盖率，也要给完整对照池相同训练与选模预算。

三档奖励自身的训练return不直接横向比较。主图按级别分别展示相应目标成功率、等级一致性、有效率；β与消融使用同一任务评价指标。

候选每个run为A+B合计200k训练决策步，33 run共6.6m步，训练期和最终评价另计。仍须先测完整端到端耗时，不能保证两天内全部收敛。

## 13. 与旧设计的关系及实施关注点

旧设计中“碰撞全部失败”“互学习教师必须低碰撞”“对抗车必须持续通行”等要求，不能直接应用于整个分级池。它们只在对应非碰撞子任务中适用。

需要按z条件化：奖励中的目标碰撞符号、成功条件、终止奖金、等级越界、质量分、选模资格、图表好坏方向。

现有Highway配对评价在碰撞时将攻击效用置零，因此L3需要独立的碰撞事件目标与评价，不是只把collision_penalty改成负值。实现时保留旧协议和旧结果身份，新建分级研究协议。

最终方法链路为：**等级与行为配置→双副本互学习训练→按等级验证→行为描述归档→多样对抗策略池→跨场景/目标鲁棒性评价**。

## 15. 基础策略训练与PPO到MAPPO的顺序

用户进一步询问是否直接使用对抗奖励冷启动，以及是否先做一蓝一红PPO+互学习，再扩展MAPPO。

推荐：**短程基础驾驶初始化→一对一普通PPO校准攻击奖励→相同设置加入互学习→扩展策略池；多对抗车协作另行决定是否需要MAPPO。**

### 15.1 目标车先固定

一蓝一红阶段只有对抗车参与梯度更新。目标车使用冻结IDM或冻结正常驾驶模型，训练副本A/B看到相同场景分布，但各自使用独立采样流。

目标车也同步学习会使训练分布不断变化，难以把收益变化归因于奖励或互学习。该研究问题应在后续明确需要同时训练攻防双方时单独设立。

场景里有两辆车不自动要求MAPPO；算法选择主要取决于哪些决策者在学习。目标固定、只有一个可学习对抗车，采用PPO即可。

目标车采用IDM适合作为首轮基准。固定的是控制规则与参数，不是恒定速度；目标仍根据前车间距、相对速度加速或制动。IDM描述纵向跟车，自主换道需另外指定MOBIL等规则。

用户最新确认基础策略允许纵向跟车和换道，因此主设定更新为IDM纵向跟车+MOBIL换道决策+横向车道跟踪。正常参考和攻击条件中的目标车均允许换道，规则及参数相同；对抗车基础初始化也需要覆盖跟车和换道。固定车道只作为定位奖励/几何问题的可选诊断，不作为最终主设定。冻结攻击策略后，再改变期望速度/跟车时距/舒适制动参数做交叉评价。不能仅给某一算法或某一攻击等级配置更弱的目标车。

正常参考与攻击条件必须采用相同IDM参数、目标初始状态和换道规则。先检查没有攻击时的正常运行，排除初始化导致的自发碰撞或停车。L3暂时无法获得碰撞时，应检查探索、事件定义和任务可达性，不因结果不理想就单独削弱目标刹车规则。

针对固定IDM训练的结论先限定于该目标配置；多参数和IDM+MOBIL交叉评价可以检验规则目标变化下的鲁棒性，但不能自动代表对任意学习型驾驶策略的泛化。

### 15.2 从头训练与基础初始化的取舍

| 控制方式 | 推荐起点 | 原因 |
|---|---|---|
| 直接输出加速度和转角 | 短驾驶初始化后按等级微调 | 减少同时学习车辆控制与攻击目标的探索负担 |
| 换道/加减速元动作，底层由控制器执行 | 可以先尝试直接攻击PPO | 已由控制器提供基本车道跟踪与动作执行能力 |

首轮优先复用现有连续控制代码及行为克隆基础设施。若改用元动作，应作为独立且统一的研究协议，不能只给某个算法使用更容易的动作空间。

从头训练不是错误路线，可用一个有界开发预实验比较；两天预算下不应未经小测就大规模展开稀疏碰撞奖励的连续控制冷启动。

### 15.3 基础驾驶初始化的最小内容

目标是具备正常前进、速度调节、航向/横向偏差恢复能力，以及后续任务所需的横向动作探索。无需先把完整正常驾驶任务训练到很高性能。

候选流程：规则控制器生成数千条训练分布样本→行为克隆拟合动作→在开发案例验证→只有能力不足时再补短程普通驾驶PPO。

示范应覆盖不同初速、速度变化、横向偏差与航向扰动。只收集完全居中的恒速直行，会让初始化缺少横向变化经验；如果示范包含不同目标指令，观测必须能识别指令，避免相同输入对应矛盾动作。

既然基础策略允许换道，还要主动收集前方慢车、邻道可用/不可用等有决策差别的示范，分别验证跟车、完成换道和保持车道等待。“允许MOBIL换道”不保证示范中实际出现换道；要统计实际换道次数及完成质量。

基础奖励围绕正常通行效率、速度调节、有效控制和碰撞/出界成本，不按换道次数持续发正奖励，避免反复横跳；居中项不能在合理换道期间持续强迫车辆返回原车道。基础资格需要覆盖跟车和换道案例，不能只看直行成功率。

候选资格为开发案例正常通行率≥90%、出界率≤5%，并检查速度调节和横向恢复；这些是准备阶段工程门槛，不是攻击组的统一成功条件。

现有highwaytest/training/driving.py已实现规则示范和行为克隆，但双车观测、角色数及旧资格条件需要适配，旧checkpoint不应未经维度/协议核对直接加载。

### 15.4 切换到攻击训练

基础驾驶主要用于初始化actor。切换后采用各等级自己的攻击奖励、成功判据和选模分数；旧普通驾驶的持续高速、无条件碰撞惩罚、最低通行进度不能全套保留到L1/L2/L3。

候选做法：加载actor权重，重新初始化或重新适配价值头，重建optimizer；保留足够的动作探索。三者的具体处理在全部对照组间一致并记录。

如果需要辅助项，应选小权重的有效控制引导，按统一训练步日程衰减。不能把大权重正常速度/通行奖励与慢行、逼停或碰撞目标长期相互抵消。

同一攻击等级下，普通PPO与互学习PPO使用同一初始化来源。若每个独立训练seed分别生成基础初始化，各方法共享对应seed的初始化；若为节约时间所有seed共享一个固定初始化，应将结论限定为给定初始化下的攻击训练，并记载该来源及成本。

### 15.5 先普通PPO，再加入互学习

| 阶段 | 做法 | 检查内容 |
|---|---|---|
| 环境校准 | 正常、阻碍、别车、碰撞脚本 | 目标可达，奖励与事件对应，没有刷分漏洞 |
| 基础初始化 | 规则示范/短驾驶训练 | 正常前进与恢复能力 |
| 攻击PPO预实验 | 一可学习对抗车+一固定目标，β=0 | 三个等级是否分别出现对应行为趋势 |
| 互学习对照 | 同一配置两个副本对齐 | 相同预算下的效果、训练稳定性与扰动鲁棒性 |
| 策略池扩展 | 由三个代表目标扩为六槽位 | 行为覆盖与等级一致性 |
| 可选MAPPO | 多个共同目标的可学习对抗车 | 是否存在需要联合决策的协作攻击问题 |

奖励校准先用单副本普通PPO即可。正式互学习消融应有相同A+B合计预算和选模方式的无互学习双副本对照，防止额外采样与从双模型选优解释收益。

PPO未获得预期行为时，先定位探索、事件可达性、初始化或奖励问题；不能依赖互学习去修复错误目标。另一方面，没有互学习收益也应保留结果，不作为“必须调到胜出”才可继续的门槛。

### 15.6 何时扩展MAPPO

如果最终策略池由单辆对抗车的不同攻击方式组成，PPO+互学习已能承载研究问题，不必把MAPPO作为必经升级。

确实增加两辆及以上共同训练的对抗车，研究配合阻碍或联合攻击，并使用集中critic时，再引入MAPPO。目标车仍可以固定。

互学习扩展为两套完整团队训练副本：团队副本A包含actor A1/A2和critic VA，团队副本B包含actor B1/B2和critic VB；按相同角色A1↔B1、A2↔B2做同输入策略对齐。它不改变为同一场景中两辆车相互模仿。

单车actor可在观测契约兼容时用于初始化团队actor；新团队critic面对不同输入与回报，应重新适配。单车结果不能直接证明多车协作收益，多车奖励和评价需要重新校准。
