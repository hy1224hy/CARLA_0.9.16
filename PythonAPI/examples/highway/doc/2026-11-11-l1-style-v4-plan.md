# L1风格奖励v4设计与实施

用户同意：L1由主要依赖红车反应改为蓝车慢速驾驶风格主导，沿用统一奖励结构；启动seed42实验及TensorBoard。

实施采用独立highway_l1_style_v4，保持v3及L2/L3源码和结果。准备进入前方后锁存慢行车道，目标速度为正常参考车的85%，红车绕行后仍保持本车道慢行。主收益为速度与车道保持，影响收益饱和且降权，另设换道/控制变化/停车成本及原失败约束。

成功拆分：style_success表示符合风格；impact_success表示有效影响；attack_success必须同时满足。单独记录各成功率，避免只要慢就算攻击成功。阶段及累计计时入观测，奖励分项分别进入TensorBoard。

先编写并确认回归测试失败，再实施；验证准备条件、绕行后目标锁存、停车无收益、碰撞失败、联合成功、存档续跑与独立评估。两组500k合计步的PPO/Mut-PPO从头训练，seed42，匹配预算/网络/环境/选模。参数冻结后启动，仅确认首轮与TensorBoard可访问，不持续监控。
